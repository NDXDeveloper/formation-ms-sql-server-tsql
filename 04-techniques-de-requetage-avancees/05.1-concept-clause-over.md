# 4.5.1 Le concept de la clause OVER()

## Introduction aux Fonctions de Fenêtrage

La clause `OVER()` est au cœur des **fonctions de fenêtrage** (ou *window functions* en anglais), une fonctionnalité puissante de T-SQL qui permet d'effectuer des calculs sur un ensemble de lignes tout en conservant les détails de chaque ligne individuelle.

### Pourquoi avons-nous besoin de OVER() ?

Avant de comprendre `OVER()`, rappelons-nous comment fonctionne une requête d'agrégation classique :

```sql
-- Requête classique avec GROUP BY
SELECT
    Departement,
    AVG(Salaire) AS SalaireMoyen
FROM Employes
GROUP BY Departement;
```

Cette requête retourne **une seule ligne par département**. Nous perdons les détails individuels de chaque employé.

**Le problème :** Et si nous voulions voir chaque employé avec son salaire, tout en affichant aussi la moyenne du département à côté ?

**La solution :** Les fonctions de fenêtrage avec `OVER()` !

## Le concept fondamental de OVER()

La clause `OVER()` permet d'appliquer une fonction (agrégation, classement, etc.) sur un "ensemble de lignes" (appelé **fenêtre**) **sans réduire le nombre de lignes** du résultat.

### Analogie simple

Imaginez une classe d'étudiants :
- **Sans OVER()** (avec GROUP BY) : Vous calculez la moyenne de la classe → Vous obtenez UN seul chiffre.
- **Avec OVER()** : Vous écrivez la moyenne de la classe à côté du nom de CHAQUE étudiant → Vous conservez tous les étudiants ET la moyenne.

## Syntaxe de base

```sql
fonction_agregation() OVER()
```

Ou plus généralement :

```sql
fonction() OVER(
    [PARTITION BY colonne1, colonne2, ...]
    [ORDER BY colonne3, ...]
    [ROWS/RANGE clause]
)
```

À ce stade, concentrons-nous sur la forme la plus simple : `OVER()` vide.

## Premier exemple : OVER() sans spécifications

```sql
SELECT
    Nom,
    Prenom,
    Salaire,
    AVG(Salaire) OVER() AS SalaireMoyenGlobal
FROM Employes;
```

### Que se passe-t-il ici ?

1. **`AVG(Salaire)`** : Calcule la moyenne des salaires
2. **`OVER()`** : Dit à SQL Server "applique cette moyenne sur TOUTES les lignes de la table"
3. **Résultat** : Chaque employé apparaît avec son salaire individuel ET la moyenne globale de tous les employés

### Exemple de résultat

| Nom | Prenom | Salaire | SalaireMoyenGlobal |
|-----|--------|---------|-------------------|
| Dupont | Marie | 45000 | 50000 |
| Martin | Paul | 55000 | 50000 |
| Durand | Sophie | 50000 | 50000 |

Remarquez : La colonne `SalaireMoyenGlobal` a la même valeur (50000) pour toutes les lignes car `OVER()` vide signifie "toute la table est ma fenêtre".

## Différence clé : GROUP BY vs OVER()

### Avec GROUP BY (Agrégation classique)

```sql
SELECT
    Departement,
    AVG(Salaire) AS SalaireMoyen
FROM Employes
GROUP BY Departement;
```

**Résultat :** Une ligne par département.

| Departement | SalaireMoyen |
|-------------|--------------|
| IT | 60000 |
| RH | 45000 |
| Ventes | 52000 |

### Avec OVER() (Fonction de fenêtrage)

```sql
SELECT
    Nom,
    Prenom,
    Departement,
    Salaire,
    AVG(Salaire) OVER() AS SalaireMoyenGlobal
FROM Employes;
```

**Résultat :** Une ligne par employé avec la moyenne globale répétée.

| Nom | Prenom | Departement | Salaire | SalaireMoyenGlobal |
|-----|--------|-------------|---------|-------------------|
| Dupont | Marie | IT | 65000 | 52333 |
| Martin | Paul | IT | 55000 | 52333 |
| Durand | Sophie | RH | 45000 | 52333 |
| Leroy | Jean | RH | 45000 | 52333 |
| Moreau | Luc | Ventes | 55000 | 52333 |
| Bernard | Claire | Ventes | 49000 | 52333 |

## Pourquoi est-ce utile ?

Les fonctions de fenêtrage avec `OVER()` sont extrêmement utiles pour :

1. **Comparaisons individuelles** : Comparer chaque ligne à une valeur agrégée
   ```sql
   SELECT
       Nom,
       Salaire,
       AVG(Salaire) OVER() AS Moyenne,
       Salaire - AVG(Salaire) OVER() AS EcartMoyenne
   FROM Employes;
   ```

2. **Afficher des totaux cumulés** : Sans perdre les détails des transactions

3. **Classements et rangs** : Attribuer des rangs tout en gardant toutes les informations

4. **Analyses comparatives** : Comparer une valeur à celle du groupe sans sous-requêtes complexes

## Fonctions utilisables avec OVER()

La clause `OVER()` peut être utilisée avec plusieurs types de fonctions :

### 1. Fonctions d'agrégation classiques
- `SUM()` : Somme
- `AVG()` : Moyenne
- `MIN()` : Minimum
- `MAX()` : Maximum
- `COUNT()` : Comptage

### 2. Fonctions de classement (que nous verrons plus tard)
- `ROW_NUMBER()`
- `RANK()`
- `DENSE_RANK()`
- `NTILE()`

### 3. Fonctions de décalage (que nous verrons plus tard)
- `LAG()`
- `LEAD()`
- `FIRST_VALUE()`
- `LAST_VALUE()`

## Exemple pratique : Comparaison au maximum

```sql
SELECT
    Nom,
    Prenom,
    Salaire,
    MAX(Salaire) OVER() AS SalaireMax,
    MAX(Salaire) OVER() - Salaire AS EcartAvecMax
FROM Employes;
```

Ce qui pourrait donner :

| Nom | Prenom | Salaire | SalaireMax | EcartAvecMax |
|-----|--------|---------|-----------|--------------|
| Dupont | Marie | 65000 | 65000 | 0 |
| Martin | Paul | 55000 | 65000 | 10000 |
| Durand | Sophie | 45000 | 65000 | 20000 |

Marie a le salaire maximum (écart = 0), tandis que Sophie est à 20 000 € du maximum.

## La "fenêtre" : Concept clé

Le terme **"fenêtre"** désigne l'ensemble de lignes sur lequel la fonction s'applique.

Avec `OVER()` vide, la fenêtre = **toutes les lignes du résultat**.

**Important :** Dans les prochaines sections, nous verrons comment :
- Diviser la fenêtre en groupes avec `PARTITION BY`
- Ordonner les lignes dans la fenêtre avec `ORDER BY`
- Définir précisément les limites de la fenêtre avec `ROWS` ou `RANGE`

## Point d'attention : Performance

Les fonctions de fenêtrage sont généralement **très performantes** car elles sont optimisées par SQL Server. Cependant :

- Elles sont calculées **après** la clause `WHERE` et `GROUP BY`
- Elles peuvent consommer de la mémoire pour les très gros jeux de données
- Utilisez-les judicieusement avec des index appropriés

## Résumé

| Aspect | Explication |
|--------|-------------|
| **Syntaxe de base** | `fonction() OVER()` |
| **Objectif** | Calculer des agrégations sans perdre les détails des lignes |
| **Différence avec GROUP BY** | GROUP BY réduit les lignes ; OVER() les conserve |
| **Fenêtre par défaut** | Toutes les lignes quand OVER() est vide |
| **Avantage principal** | Comparaison individuelle à des valeurs agrégées |
