# 3.5.1 La clause GROUP BY

## Introduction

La clause `GROUP BY` est l'un des outils les plus puissants de SQL pour analyser et résumer vos données. Elle permet de regrouper plusieurs lignes qui partagent des valeurs communes et d'effectuer des calculs sur chaque groupe.

Imaginez que vous ayez une liste de ventes avec les noms des vendeurs. Si vous voulez savoir combien chaque vendeur a vendu au total, vous devez **regrouper** toutes les ventes par vendeur, puis **additionner** les montants pour chaque groupe. C'est exactement ce que fait `GROUP BY`.

## Concept fondamental

Sans `GROUP BY`, une fonction d'agrégation comme `SUM()`, `COUNT()`, `AVG()`, etc. s'applique à **toutes les lignes** de la table et retourne **un seul résultat**.

Avec `GROUP BY`, ces mêmes fonctions s'appliquent à **chaque groupe** de lignes et retournent **un résultat par groupe**.

### Analogie simple

Pensez à un classeur avec des factures :
- **Sans GROUP BY** : Vous comptez toutes les factures du classeur → 1 seul nombre
- **Avec GROUP BY** : Vous triez les factures par client, puis vous comptez les factures de chaque client → 1 nombre par client

## Syntaxe de base

```sql
SELECT colonne_de_groupement, FONCTION_AGREGATION(colonne)
FROM nom_table
GROUP BY colonne_de_groupement;
```

### Éléments importants :
- **colonne_de_groupement** : La colonne par laquelle vous voulez regrouper les données
- **FONCTION_AGREGATION** : Une fonction comme `COUNT()`, `SUM()`, `AVG()`, `MIN()`, `MAX()`
- Toute colonne dans le `SELECT` doit être soit dans le `GROUP BY`, soit dans une fonction d'agrégation

## Exemples progressifs

### Exemple 1 : Compter le nombre de produits par catégorie

Imaginons une table `Produits` :

| ProduitID | NomProduit | Categorie | Prix |
|-----------|------------|-----------|------|
| 1 | Laptop | Informatique | 899 |
| 2 | Souris | Informatique | 25 |
| 3 | Chaise | Mobilier | 150 |
| 4 | Bureau | Mobilier | 300 |
| 5 | Clavier | Informatique | 45 |

**Requête :**
```sql
SELECT Categorie, COUNT(*) AS NombreProduits
FROM Produits
GROUP BY Categorie;
```

**Résultat :**

| Categorie | NombreProduits |
|-----------|----------------|
| Informatique | 3 |
| Mobilier | 2 |

**Explication :**
- SQL regroupe d'abord toutes les lignes qui ont la même `Categorie`
- Puis il compte le nombre de lignes dans chaque groupe
- Nous obtenons un résultat par catégorie

### Exemple 2 : Calculer le prix moyen par catégorie

**Requête :**
```sql
SELECT Categorie, AVG(Prix) AS PrixMoyen
FROM Produits
GROUP BY Categorie;
```

**Résultat :**

| Categorie | PrixMoyen |
|-----------|-----------|
| Informatique | 323.00 |
| Mobilier | 225.00 |

**Explication :**
- Pour la catégorie "Informatique" : (899 + 25 + 45) / 3 = 323
- Pour la catégorie "Mobilier" : (150 + 300) / 2 = 225

### Exemple 3 : Plusieurs fonctions d'agrégation

Vous pouvez utiliser plusieurs fonctions d'agrégation dans la même requête :

**Requête :**
```sql
SELECT
    Categorie,
    COUNT(*) AS NombreProduits,
    AVG(Prix) AS PrixMoyen,
    MIN(Prix) AS PrixMin,
    MAX(Prix) AS PrixMax,
    SUM(Prix) AS PrixTotal
FROM Produits
GROUP BY Categorie;
```

**Résultat :**

| Categorie | NombreProduits | PrixMoyen | PrixMin | PrixMax | PrixTotal |
|-----------|----------------|-----------|---------|---------|-----------|
| Informatique | 3 | 323.00 | 25 | 899 | 969 |
| Mobilier | 2 | 225.00 | 150 | 300 | 450 |

## Grouper par plusieurs colonnes

Vous pouvez regrouper vos données par plusieurs colonnes à la fois. Dans ce cas, un groupe est formé par **toutes les combinaisons uniques** des valeurs de ces colonnes.

### Exemple 4 : Table des ventes

Imaginons une table `Ventes` :

| VenteID | Vendeur | Region | Montant |
|---------|---------|--------|---------|
| 1 | Alice | Nord | 1000 |
| 2 | Alice | Nord | 1500 |
| 3 | Alice | Sud | 800 |
| 4 | Bob | Nord | 1200 |
| 5 | Bob | Sud | 900 |
| 6 | Bob | Sud | 1100 |

**Requête :**
```sql
SELECT
    Vendeur,
    Region,
    COUNT(*) AS NombreVentes,
    SUM(Montant) AS TotalVentes
FROM Ventes
GROUP BY Vendeur, Region;
```

**Résultat :**

| Vendeur | Region | NombreVentes | TotalVentes |
|---------|--------|--------------|-------------|
| Alice | Nord | 2 | 2500 |
| Alice | Sud | 1 | 800 |
| Bob | Nord | 1 | 1200 |
| Bob | Sud | 2 | 2000 |

**Explication :**
- Chaque combinaison unique de (Vendeur, Region) forme un groupe
- Nous avons 4 groupes distincts dans cet exemple

## Règles importantes à retenir

### Règle n°1 : Toute colonne dans SELECT doit être dans GROUP BY ou dans une fonction d'agrégation

❌ **INCORRECT :**
```sql
SELECT Categorie, NomProduit, COUNT(*)
FROM Produits
GROUP BY Categorie;
```

Cette requête génère une erreur car `NomProduit` n'est ni dans le `GROUP BY` ni dans une fonction d'agrégation. SQL ne sait pas quel nom de produit afficher pour chaque groupe de catégorie.

✅ **CORRECT :**
```sql
SELECT Categorie, COUNT(*)
FROM Produits
GROUP BY Categorie;
```

ou

✅ **CORRECT :**
```sql
SELECT Categorie, NomProduit, COUNT(*)
FROM Produits
GROUP BY Categorie, NomProduit;
```

### Règle n°2 : GROUP BY s'exécute avant SELECT

Dans l'ordre logique d'exécution d'une requête SQL :
1. `FROM` : SQL identifie la table source
2. `WHERE` : SQL filtre les lignes **avant** le regroupement
3. `GROUP BY` : SQL crée les groupes
4. `SELECT` : SQL calcule les agrégations pour chaque groupe
5. `ORDER BY` : SQL trie les résultats

Cela signifie que vous ne pouvez pas utiliser un alias défini dans le `SELECT` dans le `GROUP BY`.

❌ **INCORRECT :**
```sql
SELECT Categorie AS Cat, COUNT(*) AS Nombre
FROM Produits
GROUP BY Cat;  -- L'alias 'Cat' n'existe pas encore
```

✅ **CORRECT :**
```sql
SELECT Categorie AS Cat, COUNT(*) AS Nombre
FROM Produits
GROUP BY Categorie;  -- Utilisez le nom de colonne original
```

### Règle n°3 : WHERE filtre avant GROUP BY

La clause `WHERE` filtre les lignes **avant** qu'elles ne soient regroupées.

**Exemple :**
```sql
SELECT Categorie, COUNT(*) AS NombreProduits
FROM Produits
WHERE Prix > 100
GROUP BY Categorie;
```

**Ordre d'exécution :**
1. SQL filtre d'abord les produits avec `Prix > 100`
2. Ensuite, il regroupe les lignes restantes par `Categorie`
3. Enfin, il compte le nombre de produits dans chaque groupe

## Utilisation avec WHERE

Vous pouvez combiner `WHERE` et `GROUP BY` pour filtrer les données avant de les regrouper.

**Exemple :**
```sql
SELECT
    Categorie,
    COUNT(*) AS NombreProduits,
    AVG(Prix) AS PrixMoyen
FROM Produits
WHERE Prix >= 50
GROUP BY Categorie;
```

Cette requête :
1. Ne considère que les produits dont le prix est supérieur ou égal à 50
2. Regroupe ces produits par catégorie
3. Calcule le nombre et le prix moyen pour chaque catégorie

## Cas particulier : GROUP BY sans fonction d'agrégation

Techniquement, vous pouvez utiliser `GROUP BY` sans fonction d'agrégation. Dans ce cas, il agit comme un `DISTINCT` avancé.

**Exemple :**
```sql
SELECT Categorie
FROM Produits
GROUP BY Categorie;
```

Cela retourne la liste des catégories uniques, similaire à :

```sql
SELECT DISTINCT Categorie
FROM Produits;
```

Cependant, cette pratique n'est pas recommandée car elle peut prêter à confusion. Si vous voulez simplement des valeurs uniques, utilisez `DISTINCT`.

## Utilisation avec NULL

Les valeurs `NULL` sont traitées comme une valeur distincte dans `GROUP BY`. Toutes les lignes avec `NULL` dans la colonne de regroupement formeront un seul groupe.

**Exemple :**
Si certains produits n'ont pas de catégorie (valeur `NULL`) :

```sql
SELECT Categorie, COUNT(*) AS NombreProduits
FROM Produits
GROUP BY Categorie;
```

Vous obtiendrez un groupe pour `NULL` contenant tous les produits sans catégorie.

## Récapitulatif

La clause `GROUP BY` permet de :
- **Regrouper** des lignes qui partagent des valeurs communes
- **Appliquer** des fonctions d'agrégation sur chaque groupe
- **Analyser** les données par catégorie, par période, par région, etc.

**Points clés à retenir :**
- Toute colonne dans `SELECT` doit être dans `GROUP BY` ou dans une fonction d'agrégation
- `WHERE` filtre **avant** le regroupement
- Vous pouvez grouper par plusieurs colonnes
- L'ordre d'exécution : `FROM` → `WHERE` → `GROUP BY` → `SELECT` → `ORDER BY`

La clause `GROUP BY` est souvent utilisée en combinaison avec `HAVING` (pour filtrer les groupes après agrégation), mais cela sera couvert dans la section suivante.

## Exemples récapitulatifs

### Compter les employés par département
```sql
SELECT Departement, COUNT(*) AS NombreEmployes
FROM Employes
GROUP BY Departement;
```

### Calculer le salaire total par département
```sql
SELECT Departement, SUM(Salaire) AS MasseSalariale
FROM Employes
GROUP BY Departement;
```

### Analyser les ventes par année et par trimestre
```sql
SELECT
    YEAR(DateVente) AS Annee,
    DATEPART(QUARTER, DateVente) AS Trimestre,
    COUNT(*) AS NombreVentes,
    SUM(Montant) AS ChiffreAffaires
FROM Ventes
GROUP BY YEAR(DateVente), DATEPART(QUARTER, DateVente)
ORDER BY Annee, Trimestre;
```

### Trouver le prix minimum et maximum par fournisseur
```sql
SELECT
    FournisseurID,
    MIN(Prix) AS PrixMin,
    MAX(Prix) AS PrixMax,
    MAX(Prix) - MIN(Prix) AS Ecart
FROM Produits
GROUP BY FournisseurID;
```
