# 8.1.2 Interrogation avec XQuery (.nodes(), .value())

## Introduction à XQuery

Maintenant que nous savons stocker des données XML dans SQL Server, la question suivante est : **comment extraire des informations spécifiques de ces données XML ?**

C'est là qu'intervient **XQuery** (XML Query Language), un langage de requête spécialement conçu pour interroger des données XML, tout comme SQL est utilisé pour interroger des données relationnelles.

SQL Server implémente XQuery à travers plusieurs **méthodes** que l'on applique aux colonnes de type XML. Les deux méthodes les plus importantes pour extraire des données sont :

- **`.value()`** : Extrait une valeur unique
- **`.nodes()`** : Décompose le XML en plusieurs lignes

## Préparation : Données d'exemple

Pour illustrer ces méthodes, créons une table avec des données XML :

```sql
-- Créer la table
CREATE TABLE Produits (
    ProduitID INT PRIMARY KEY,
    NomProduit NVARCHAR(100),
    DetailsXML XML
);

-- Insérer des données d'exemple
INSERT INTO Produits VALUES
(1, 'Ordinateur',
'<Details>
    <Specifications>
        <Processeur>Intel i7</Processeur>
        <RAM>16</RAM>
        <DisqueDur>512</DisqueDur>
    </Specifications>
    <Prix devise="EUR">899.99</Prix>
    <Stock>15</Stock>
</Details>'),

(2, 'Smartphone',
'<Details>
    <Specifications>
        <Processeur>Snapdragon 888</Processeur>
        <RAM>8</RAM>
        <Stockage>128</Stockage>
    </Specifications>
    <Prix devise="EUR">599.99</Prix>
    <Stock>42</Stock>
</Details>'),

(3, 'Tablette',
'<Details>
    <Specifications>
        <Processeur>Apple M1</Processeur>
        <RAM>8</RAM>
        <Stockage>256</Stockage>
    </Specifications>
    <Prix devise="USD">799.00</Prix>
    <Stock>8</Stock>
</Details>');
```

## La méthode .value()

### Concept de base

La méthode **`.value()`** permet d'extraire **une seule valeur** d'un document XML. C'est la méthode la plus simple pour récupérer une information précise.

### Syntaxe

```sql
colonne_XML.value('expression_XQuery', 'type_SQL')
```

**Paramètres** :
1. **'expression_XQuery'** : Le chemin vers l'élément à extraire (entre guillemets simples)
2. **'type_SQL'** : Le type de données SQL du résultat (VARCHAR, INT, DECIMAL, etc.)

### Chemin XQuery de base

Pour naviguer dans le XML, on utilise une notation avec des `/` (slash), similaire aux chemins de fichiers :

```
/Racine/Element/SousElement
```

**Important** : Les chemins XQuery sont **sensibles à la casse** !

### Exemples simples avec .value()

#### Exemple 1 : Extraire un élément simple

Extraire le stock de chaque produit :

```sql
SELECT
    ProduitID,
    NomProduit,
    DetailsXML.value('(/Details/Stock)[1]', 'INT') AS Stock
FROM Produits;
```

**Résultat** :
```
ProduitID | NomProduit  | Stock
----------|-------------|------
1         | Ordinateur  | 15
2         | Smartphone  | 42
3         | Tablette    | 8
```

**Explication** :
- `(/Details/Stock)[1]` : Chemin vers l'élément `<Stock>`
- Le `[1]` indique qu'on veut la **première occurrence** (obligatoire avec `.value()`)
- `'INT'` : On convertit la valeur en entier SQL

#### Exemple 2 : Extraire un élément imbriqué

Extraire le processeur (qui est dans `<Specifications>`) :

```sql
SELECT
    ProduitID,
    NomProduit,
    DetailsXML.value('(/Details/Specifications/Processeur)[1]', 'NVARCHAR(50)') AS Processeur
FROM Produits;
```

**Résultat** :
```
ProduitID | NomProduit  | Processeur
----------|-------------|------------------
1         | Ordinateur  | Intel i7
2         | Smartphone  | Snapdragon 888
3         | Tablette    | Apple M1
```

#### Exemple 3 : Extraire un attribut

Pour extraire la valeur d'un **attribut** (comme `devise` dans `<Prix devise="EUR">`), on utilise `@` :

```sql
SELECT
    ProduitID,
    NomProduit,
    DetailsXML.value('(/Details/Prix/@devise)[1]', 'NVARCHAR(10)') AS Devise,
    DetailsXML.value('(/Details/Prix)[1]', 'DECIMAL(10,2)') AS Prix
FROM Produits;
```

**Résultat** :
```
ProduitID | NomProduit  | Devise | Prix
----------|-------------|--------|-------
1         | Ordinateur  | EUR    | 899.99
2         | Smartphone  | EUR    | 599.99
3         | Tablette    | USD    | 799.00
```

**Explication** :
- `@devise` permet d'accéder à l'attribut `devise`
- On peut extraire à la fois l'attribut et la valeur de l'élément

### Pourquoi le [1] est obligatoire ?

La méthode `.value()` ne peut retourner qu'**une seule valeur**. Le `[1]` indique à SQL Server de prendre le premier élément trouvé. Si vous l'oubliez, vous aurez une erreur :

```sql
-- ERREUR : XQuery doit retourner une valeur singleton
SELECT DetailsXML.value('(/Details/Stock)', 'INT')
FROM Produits;
```

## La méthode .nodes()

### Concept de base

Que se passe-t-il si notre XML contient **plusieurs éléments répétés** ? Par exemple, une commande avec plusieurs articles ?

Considérons ce XML :

```xml
<Commande>
    <Articles>
        <Article>
            <Code>A001</Code>
            <Nom>Clavier</Nom>
            <Quantite>2</Quantite>
        </Article>
        <Article>
            <Code>A002</Code>
            <Nom>Souris</Nom>
            <Quantite>3</Quantite>
        </Article>
        <Article>
            <Code>A003</Code>
            <Nom>Écran</Nom>
            <Quantite>1</Quantite>
        </Article>
    </Articles>
</Commande>
```

La méthode **`.nodes()`** permet de "décomposer" (ou "fragmenter") le XML pour obtenir **une ligne par élément répété**.

### Syntaxe

```sql
CROSS APPLY colonne_XML.nodes('expression_XQuery') AS Alias(NodeXML)
```

**Explication** :
- `CROSS APPLY` : Opérateur qui applique la méthode `.nodes()` pour chaque ligne
- `'expression_XQuery'` : Le chemin vers les éléments répétés
- `AS Alias(NodeXML)` : Crée un alias pour la table et la colonne résultantes

### Exemple complet avec .nodes()

Créons d'abord une table avec des commandes contenant plusieurs articles :

```sql
-- Créer la table
CREATE TABLE Commandes (
    CommandeID INT PRIMARY KEY,
    Client NVARCHAR(100),
    CommandeXML XML
);

-- Insérer une commande avec plusieurs articles
INSERT INTO Commandes VALUES
(1, 'Société ABC',
'<Commande>
    <Articles>
        <Article>
            <Code>A001</Code>
            <Nom>Clavier mécanique</Nom>
            <Quantite>2</Quantite>
            <PrixUnitaire>79.99</PrixUnitaire>
        </Article>
        <Article>
            <Code>A002</Code>
            <Nom>Souris gaming</Nom>
            <Quantite>3</Quantite>
            <PrixUnitaire>49.99</PrixUnitaire>
        </Article>
        <Article>
            <Code>A003</Code>
            <Nom>Écran 27 pouces</Nom>
            <Quantite>1</Quantite>
            <PrixUnitaire>299.99</PrixUnitaire>
        </Article>
    </Articles>
</Commande>');
```

Maintenant, extrayons chaque article dans une ligne séparée :

```sql
SELECT
    C.CommandeID,
    C.Client,
    Article.value('(Code)[1]', 'NVARCHAR(20)') AS CodeArticle,
    Article.value('(Nom)[1]', 'NVARCHAR(100)') AS NomArticle,
    Article.value('(Quantite)[1]', 'INT') AS Quantite,
    Article.value('(PrixUnitaire)[1]', 'DECIMAL(10,2)') AS PrixUnitaire
FROM Commandes C
CROSS APPLY C.CommandeXML.nodes('/Commande/Articles/Article') AS T(Article);
```

**Résultat** :
```
CommandeID | Client       | CodeArticle | NomArticle           | Quantite | PrixUnitaire
-----------|--------------|-------------|----------------------|----------|-------------
1          | Société ABC  | A001        | Clavier mécanique    | 2        | 79.99
1          | Société ABC  | A002        | Souris gaming        | 3        | 49.99
1          | Société ABC  | A003        | Écran 27 pouces      | 1        | 299.99
```

**Explication détaillée** :

1. `.nodes('/Commande/Articles/Article')` : Indique le chemin vers les éléments répétés
2. `AS T(Article)` : Crée une table virtuelle `T` avec une colonne `Article` contenant chaque nœud XML
3. `Article.value(...)` : Extrait les valeurs de chaque nœud individuel
4. **Important** : Dans `.value()` après `.nodes()`, le chemin est **relatif** au nœud courant, donc on écrit `(Code)[1]` et non `(/Commande/Articles/Article/Code)[1]`

### Calculs sur les données extraites

Une fois les données extraites, on peut effectuer des calculs SQL classiques :

```sql
SELECT
    C.CommandeID,
    C.Client,
    Article.value('(Code)[1]', 'NVARCHAR(20)') AS CodeArticle,
    Article.value('(Nom)[1]', 'NVARCHAR(100)') AS NomArticle,
    Article.value('(Quantite)[1]', 'INT') AS Quantite,
    Article.value('(PrixUnitaire)[1]', 'DECIMAL(10,2)') AS PrixUnitaire,
    Article.value('(Quantite)[1]', 'INT') *
    Article.value('(PrixUnitaire)[1]', 'DECIMAL(10,2)') AS MontantTotal
FROM Commandes C
CROSS APPLY C.CommandeXML.nodes('/Commande/Articles/Article') AS T(Article);
```

**Résultat** :
```
CommandeID | Client      | CodeArticle | NomArticle        | Quantite | PrixUnitaire | MontantTotal
-----------|-------------|-------------|-------------------|----------|--------------|-------------
1          | Société ABC | A001        | Clavier mécanique | 2        | 79.99        | 159.98
1          | Société ABC | A002        | Souris gaming     | 3        | 49.99        | 149.97
1          | Société ABC | A003        | Écran 27 pouces   | 1        | 299.99       | 299.99
```

### Agrégation après .nodes()

On peut aussi agréger les résultats, par exemple pour calculer le total d'une commande :

```sql
SELECT
    C.CommandeID,
    C.Client,
    COUNT(*) AS NombreArticles,
    SUM(Article.value('(Quantite)[1]', 'INT') *
        Article.value('(PrixUnitaire)[1]', 'DECIMAL(10,2)')) AS TotalCommande
FROM Commandes C
CROSS APPLY C.CommandeXML.nodes('/Commande/Articles/Article') AS T(Article)
GROUP BY C.CommandeID, C.Client;
```

**Résultat** :
```
CommandeID | Client       | NombreArticles | TotalCommande
-----------|--------------|----------------|---------------
1          | Société ABC  | 3              | 609.94
```

## Combiner .nodes() et .value() : Cas complexe

Parfois, on doit extraire à la fois des données au niveau de la racine ET des éléments répétés. Voici un exemple avec plusieurs commandes :

```sql
-- Insérer une deuxième commande
INSERT INTO Commandes VALUES
(2, 'Entreprise XYZ',
'<Commande>
    <DateCommande>2024-11-15</DateCommande>
    <Articles>
        <Article>
            <Code>B001</Code>
            <Nom>Laptop</Nom>
            <Quantite>5</Quantite>
            <PrixUnitaire>899.99</PrixUnitaire>
        </Article>
        <Article>
            <Code>B002</Code>
            <Nom>Sacoche</Nom>
            <Quantite>5</Quantite>
            <PrixUnitaire>39.99</PrixUnitaire>
        </Article>
    </Articles>
</Commande>');

-- Requête combinant .value() et .nodes()
SELECT
    C.CommandeID,
    C.Client,
    C.CommandeXML.value('(/Commande/DateCommande)[1]', 'DATE') AS DateCommande,
    Article.value('(Code)[1]', 'NVARCHAR(20)') AS CodeArticle,
    Article.value('(Nom)[1]', 'NVARCHAR(100)') AS NomArticle,
    Article.value('(Quantite)[1]', 'INT') AS Quantite,
    Article.value('(PrixUnitaire)[1]', 'DECIMAL(10,2)') AS PrixUnitaire
FROM Commandes C
CROSS APPLY C.CommandeXML.nodes('/Commande/Articles/Article') AS T(Article)
ORDER BY C.CommandeID;
```

**Résultat** :
```
CommandeID | Client         | DateCommande | CodeArticle | NomArticle        | Quantite | PrixUnitaire
-----------|----------------|--------------|-------------|-------------------|----------|-------------
1          | Société ABC    | NULL         | A001        | Clavier mécanique | 2        | 79.99
1          | Société ABC    | NULL         | A002        | Souris gaming     | 3        | 49.99
1          | Société ABC    | NULL         | A003        | Écran 27 pouces   | 1        | 299.99
2          | Entreprise XYZ | 2024-11-15   | B001        | Laptop            | 5        | 899.99
2          | Entreprise XYZ | 2024-11-15   | B002        | Sacoche           | 5        | 39.99
```

**Note** : La commande 1 retourne NULL pour DateCommande car cet élément n'existe pas dans son XML.

## Filtrage avec XQuery

On peut aussi filtrer directement dans l'expression XQuery avec des **prédicats** entre crochets `[]`.

### Exemple : Filtrer sur une valeur

Extraire uniquement les articles avec une quantité supérieure à 1 :

```sql
SELECT
    C.CommandeID,
    C.Client,
    Article.value('(Code)[1]', 'NVARCHAR(20)') AS CodeArticle,
    Article.value('(Nom)[1]', 'NVARCHAR(100)') AS NomArticle,
    Article.value('(Quantite)[1]', 'INT') AS Quantite
FROM Commandes C
CROSS APPLY C.CommandeXML.nodes('/Commande/Articles/Article[Quantite > 1]') AS T(Article);
```

**Résultat** :
```
CommandeID | Client         | CodeArticle | NomArticle        | Quantite
-----------|----------------|-------------|-------------------|----------
1          | Société ABC    | A001        | Clavier mécanique | 2
1          | Société ABC    | A002        | Souris gaming     | 3
2          | Entreprise XYZ | B001        | Laptop            | 5
2          | Entreprise XYZ | B002        | Sacoche           | 5
```

L'article "Écran 27 pouces" (quantité = 1) n'apparaît pas dans les résultats.

## Gestion des espaces de noms (Namespaces)

Certains documents XML utilisent des **espaces de noms** (namespaces). C'est un peu plus complexe, mais voici un aperçu :

```xml
<Commande xmlns="http://example.com/orders">
    <Article>
        <Code>A001</Code>
    </Article>
</Commande>
```

Pour interroger ce XML, il faut déclarer l'espace de noms :

```sql
-- Déclaration WITH XMLNAMESPACES
WITH XMLNAMESPACES(DEFAULT 'http://example.com/orders')
SELECT
    CommandeXML.value('(/Commande/Article/Code)[1]', 'NVARCHAR(20)') AS Code
FROM Commandes;
```

**Note pour débutants** : Si vous rencontrez des erreurs avec XQuery et que le XML contient `xmlns=`, c'est probablement un problème d'espace de noms. Dans la pratique, pour débuter, travaillez avec du XML sans namespace.

## Comparaison : .value() vs .nodes()

| Aspect | .value() | .nodes() |
|--------|----------|----------|
| **Utilisation** | Extraire UNE valeur | Décomposer en PLUSIEURS lignes |
| **Résultat** | Une seule valeur par ligne de table | Plusieurs lignes (une par nœud XML) |
| **Syntaxe** | `.value('xpath[1]', 'type')` | `.nodes('xpath')` + `.value()` |
| **Cas d'usage** | Élément unique | Éléments répétés |
| **Exemple** | Extraire le prix d'un produit | Extraire chaque article d'une commande |

## Performance : Bonnes pratiques

1. **Indexation** : On peut créer des index XML pour accélérer les requêtes XQuery
2. **Éviter les extractions répétées** : Si possible, extrayez les données XML vers des colonnes relationnelles pour des performances optimales
3. **Filtrage** : Utilisez des prédicats XQuery (`[condition]`) pour filtrer au niveau XML plutôt qu'avec WHERE après extraction
4. **Type de données** : Utilisez le type SQL approprié pour éviter les conversions inutiles

## Résumé des syntaxes

### Syntaxe .value()
```sql
colonne_XML.value('(chemin/vers/element)[1]', 'TYPE_SQL')
colonne_XML.value('(chemin/vers/element/@attribut)[1]', 'TYPE_SQL')
```

### Syntaxe .nodes()
```sql
FROM Table
CROSS APPLY colonne_XML.nodes('chemin/vers/elements/repetes') AS Alias(Noeud)
-- Puis utiliser Noeud.value() pour extraire les valeurs
```

### Chemin XQuery
```
/Racine/Element/SousElement          -- Navigation normale
/Racine/Element/@attribut            -- Accès à un attribut
/Racine/Element[condition]           -- Filtrage
(expression)[1]                      -- Première occurrence (obligatoire avec .value())
```

## Conclusion

Les méthodes `.value()` et `.nodes()` sont les outils essentiels pour interroger des données XML dans SQL Server :

- **`.value()`** est parfait pour extraire des valeurs simples et uniques
- **`.nodes()`** est indispensable pour travailler avec des éléments répétés

Ensemble, ces méthodes permettent de transformer des données XML hiérarchiques en résultats relationnels exploitables avec SQL classique.
