# 5.1.1 Déclaration (DECLARE) et assignation (SET, SELECT)

## Introduction

Les **variables** sont des espaces en mémoire qui permettent de stocker temporairement des valeurs pendant l'exécution de votre code T-SQL. Elles sont essentielles pour créer des scripts dynamiques, effectuer des calculs intermédiaires ou stocker des résultats temporaires.

Dans cette section, nous allons découvrir comment déclarer des variables et leur attribuer des valeurs.

---

## 1. Déclaration de variables avec DECLARE

### Qu'est-ce qu'une variable ?

Une variable est un conteneur nommé qui stocke une valeur d'un type de données spécifique. En T-SQL, toutes les variables locales commencent par le symbole **@** (arobase).

### Syntaxe de base

```sql
DECLARE @NomVariable TypeDeDonnees;
```

**Exemple :**

```sql
DECLARE @Age INT;
DECLARE @Prenom VARCHAR(50);
DECLARE @DateNaissance DATE;
```

### Points importants à retenir

1. **Toutes les variables locales commencent par @**
2. **Le type de données est obligatoire** (INT, VARCHAR, DATE, etc.)
3. **Les variables doivent être déclarées avant d'être utilisées**
4. **Les variables sont locales au batch** (elles n'existent que dans le contexte où elles sont déclarées)

### Déclarer plusieurs variables en une fois

Vous pouvez déclarer plusieurs variables dans une seule instruction DECLARE en les séparant par des virgules :

```sql
DECLARE
    @Prenom VARCHAR(50),
    @Nom VARCHAR(50),
    @Age INT;
```

---

## 2. Assignation de valeurs : la méthode SET

La première méthode pour attribuer une valeur à une variable est d'utiliser l'instruction **SET**.

### Syntaxe

```sql
SET @NomVariable = valeur;
```

### Exemples

```sql
-- Déclaration
DECLARE @Age INT;

-- Assignation
SET @Age = 25;

-- Affichage du résultat
SELECT @Age AS Age;
```

**Résultat :**
```
Age
---
25
```

### Exemples avec différents types de données

```sql
DECLARE
    @Prenom VARCHAR(50),
    @Salaire DECIMAL(10,2),
    @DateEmbauche DATE,
    @EstActif BIT;

SET @Prenom = 'Marie';
SET @Salaire = 3500.50;
SET @DateEmbauche = '2024-01-15';
SET @EstActif = 1; -- 1 = vrai, 0 = faux

SELECT
    @Prenom AS Prenom,
    @Salaire AS Salaire,
    @DateEmbauche AS DateEmbauche,
    @EstActif AS EstActif;
```

### Caractéristiques de SET

- **SET ne peut assigner qu'une seule variable à la fois**
- **SET est la méthode recommandée pour l'assignation simple**
- **SET est plus lisible et explicite**

---

## 3. Assignation de valeurs : la méthode SELECT

La deuxième méthode pour assigner des valeurs aux variables utilise l'instruction **SELECT**.

### Syntaxe de base

```sql
SELECT @NomVariable = valeur;
```

### Exemple simple

```sql
DECLARE @Ville VARCHAR(50);

SELECT @Ville = 'Paris';

SELECT @Ville AS Ville;
```

### Avantage : Assignation multiple

Contrairement à SET, SELECT permet d'assigner plusieurs variables en une seule instruction :

```sql
DECLARE
    @Prenom VARCHAR(50),
    @Nom VARCHAR(50),
    @Age INT;

SELECT
    @Prenom = 'Jean',
    @Nom = 'Dupont',
    @Age = 30;

SELECT
    @Prenom AS Prenom,
    @Nom AS Nom,
    @Age AS Age;
```

## 4. Assignation à partir d'une requête

L'un des usages les plus puissants des variables est de stocker le résultat d'une requête.

### Avec SET (requête scalaire)

```sql
DECLARE @NombreEmployes INT;

-- Récupérer le nombre total d'employés
SET @NombreEmployes = (SELECT COUNT(*) FROM Employes);

SELECT @NombreEmployes AS TotalEmployes;
```

**Note importante :** Avec SET, la requête doit retourner **une seule valeur** (requête scalaire). Si elle retourne plusieurs lignes, une erreur sera générée.

### Avec SELECT (plus flexible)

```sql
DECLARE @NomEmploye VARCHAR(100);

-- Récupérer le nom d'un employé spécifique
SELECT @NomEmploye = Prenom + ' ' + Nom
FROM Employes
WHERE EmployeID = 5;

SELECT @NomEmploye AS NomComplet;
```

### Assignation de plusieurs colonnes

```sql
DECLARE
    @Prenom VARCHAR(50),
    @Nom VARCHAR(50),
    @Salaire DECIMAL(10,2);

-- Récupérer plusieurs valeurs d'un employé
SELECT
    @Prenom = Prenom,
    @Nom = Nom,
    @Salaire = Salaire
FROM Employes
WHERE EmployeID = 10;

SELECT
    @Prenom AS Prenom,
    @Nom AS Nom,
    @Salaire AS Salaire;
```

## 5. Différences entre SET et SELECT

| Critère | SET | SELECT |
|---------|-----|--------|
| **Nombre de variables** | Une seule à la fois | Plusieurs simultanément |
| **Performance** | Légèrement plus rapide pour une seule variable | Plus rapide pour plusieurs variables |
| **Requête retournant plusieurs lignes** | Génère une erreur | Prend la dernière valeur (attention !) |
| **Lisibilité** | Plus explicite pour une assignation simple | Plus compact pour plusieurs variables |
| **Standard ANSI** | Oui (recommandé) | Extension T-SQL |

### Attention : comportement avec plusieurs lignes

```sql
DECLARE @NomEmploye VARCHAR(100);

-- Si cette requête retourne plusieurs lignes
SELECT @NomEmploye = Prenom + ' ' + Nom
FROM Employes
WHERE Departement = 'Ventes';

-- La variable contiendra la DERNIÈRE valeur lue (comportement imprévisible)
SELECT @NomEmploye AS DernierNom;
```

**Conseil :** Utilisez toujours une clause WHERE appropriée pour garantir qu'une seule ligne est retournée, ou utilisez SET avec une sous-requête si vous voulez être certain de n'avoir qu'une valeur.

### Attention : comportement avec zéro ligne (différence majeure)

Si la requête d'assignation ne retourne **aucune ligne**, `SET` et `SELECT` se comportent **différemment** :

```sql
DECLARE @Nom VARCHAR(100) = 'Valeur initiale';

-- SELECT : si aucune ligne, la variable reste INCHANGÉE
SELECT @Nom = Nom FROM Employes WHERE EmployeID = -1;  -- aucun employé
SELECT @Nom AS ResultatSelect;   -- → 'Valeur initiale' (inchangée !)

DECLARE @Nom2 VARCHAR(100) = 'Valeur initiale';

-- SET : si aucune ligne, la variable devient NULL
SET @Nom2 = (SELECT Nom FROM Employes WHERE EmployeID = -1);
SELECT @Nom2 AS ResultatSet;     -- → NULL
```

C'est un piège fréquent : avec `SELECT`, une variable peut **conserver une ancienne valeur** quand la requête ne ramène rien (par exemple dans une boucle), ce qui produit des résultats erronés difficiles à diagnostiquer.

## 6. Valeurs initiales des variables

### Valeur NULL par défaut

Lorsqu'une variable est déclarée sans valeur initiale, elle contient **NULL** :

```sql
DECLARE @Compteur INT;

SELECT @Compteur AS Valeur; -- Résultat : NULL
```

### Initialisation lors de la déclaration

Vous pouvez initialiser une variable directement lors de sa déclaration :

```sql
DECLARE @Compteur INT = 0;
DECLARE @Message VARCHAR(50) = 'Bonjour';

SELECT @Compteur AS Compteur, @Message AS Message;
```

**Résultat :**
```
Compteur  Message
--------  -------
0         Bonjour
```

## 7. Exemples pratiques complets

### Exemple 1 : Calcul avec des variables

```sql
DECLARE
    @PrixHT DECIMAL(10,2) = 100.00,
    @TauxTVA DECIMAL(5,2) = 20.00,
    @PrixTTC DECIMAL(10,2);

-- Calcul du prix TTC
SET @PrixTTC = @PrixHT * (1 + @TauxTVA / 100);

SELECT
    @PrixHT AS PrixHT,
    @TauxTVA AS TauxTVA,
    @PrixTTC AS PrixTTC;
```

**Résultat :**
```
PrixHT   TauxTVA   PrixTTC
------   -------   -------
100.00   20.00     120.00
```

### Exemple 2 : Concaténation de chaînes

```sql
DECLARE
    @Prenom VARCHAR(50) = 'Sophie',
    @Nom VARCHAR(50) = 'Martin',
    @NomComplet VARCHAR(100);

SET @NomComplet = @Prenom + ' ' + @Nom;

SELECT @NomComplet AS NomComplet;
```

**Résultat :**
```
NomComplet
-----------
Sophie Martin
```

### Exemple 3 : Utilisation dans des requêtes

```sql
DECLARE @DepartementRecherche VARCHAR(50) = 'Informatique';

-- Utiliser la variable dans une clause WHERE
SELECT
    Prenom,
    Nom,
    Salaire
FROM Employes
WHERE Departement = @DepartementRecherche
ORDER BY Salaire DESC;
```

## 8. Bonnes pratiques

### ✅ À FAIRE

1. **Toujours déclarer les variables avant de les utiliser**
2. **Utiliser des noms de variables significatifs**
   - ✅ `@SalaireAnnuel` plutôt que `@s`
3. **Initialiser les variables si une valeur par défaut est nécessaire**
4. **Utiliser SET pour une seule variable (plus lisible)**
5. **Utiliser SELECT pour assigner plusieurs variables simultanément**

### ❌ À ÉVITER

1. **Ne pas utiliser de variables sans les déclarer**
2. **Éviter les noms de variables trop courts ou cryptiques**
3. **Ne pas compter sur l'ordre des lignes avec SELECT pour l'assignation**
4. **Ne pas oublier que les variables non initialisées valent NULL**

---

## Résumé

- Les **variables** permettent de stocker temporairement des valeurs en T-SQL
- Les variables locales commencent toujours par **@**
- **DECLARE** sert à créer une variable avec un type de données spécifique
- **SET** assigne une valeur à **une seule variable** (méthode standard recommandée)
- **SELECT** peut assigner plusieurs variables à la fois
- Les variables non initialisées contiennent **NULL** par défaut
- Vous pouvez initialiser une variable lors de sa déclaration
- Les variables peuvent stocker les résultats de requêtes
