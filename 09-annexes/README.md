# 📎 Annexes

## Introduction

Ces annexes complètent la formation par des ressources **pratiques** et de **référence**. Elles sont conçues pour être consultées **au fil de votre apprentissage** : installez votre environnement (annexe A), créez la base d'exemple (annexe B), entraînez-vous (annexe C), et gardez les annexes de référence (D à H) à portée de main.

> 🆕 Ces annexes ont été ajoutées pour faire de ce cours une formation complète et autonome.

---

## Comment utiliser ces annexes

```
1. ANNEXE A : préparez votre environnement (1 fois)
        ↓
2. ANNEXE B : créez la base d'exemple (1 fois)
        ↓
3. CHAPITRES 1 → 8 : apprenez, en pratiquant sur la base d'exemple
        ↓  (après chaque chapitre)
4. ANNEXE C : faites les exercices correspondants
        ↓  (en continu)
5. ANNEXES D → H : consultez-les comme références
```

> 💡 **Conseil** : gardez l'aide-mémoire (D), le tableau des types (E) et le glossaire (G) ouverts dans un onglet pendant que vous travaillez. Ils vous feront gagner un temps précieux.
