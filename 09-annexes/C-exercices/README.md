# Annexe C — Exercices et TP corrigés

## Introduction

La théorie ne suffit pas : c'est en **pratiquant** qu'on apprend vraiment le SQL. Cette annexe propose un jeu d'**exercices corrigés** pour chaque chapitre de la formation. Tous s'appuient sur la base d'exemple **`Boutique`** (voir [annexe B](/09-annexes/B-base-exemple/README.md)) — installez-la avant de commencer.

---

## Comment utiliser ces exercices

```
1. Lisez le chapitre correspondant.
2. Installez/réinitialisez la base Boutique (annexe B).
3. Essayez de résoudre CHAQUE exercice PAR VOUS-MÊME d'abord.
4. Comparez ensuite avec le corrigé et l'explication.
5. Expérimentez : modifiez l'exercice, posez-vous d'autres questions.
```

> 💡 **Le piège à éviter** : regarder le corrigé trop vite. La difficulté féconde — chercher, se tromper, recommencer — est ce qui ancre l'apprentissage. Donnez-vous au moins quelques minutes par exercice avant de regarder la solution.

Chaque série suit une **difficulté progressive** : ⭐ (facile) → ⭐⭐ (intermédiaire) → ⭐⭐⭐ (avancé).

## Conventions

- 📝 **Énoncé** : la question posée.
- 💡 **Indice** : une piste si vous bloquez (à lire avant le corrigé).
- ✅ **Corrigé** : une solution possible (il en existe souvent plusieurs !).
- 🧠 **Explication** : pourquoi cette solution, et les pièges à éviter.

> ⚠️ Les corrigés SQL supposent la base `Boutique` telle que créée par le script de l'annexe B. Les résultats exacts dépendent des données insérées.
