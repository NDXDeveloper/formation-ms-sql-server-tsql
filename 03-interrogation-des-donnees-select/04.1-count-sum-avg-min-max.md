# 3.4.1 COUNT(), SUM(), AVG(), MIN(), MAX()

## Introduction

Jusqu'à présent, nous avons appris à récupérer des lignes individuelles d'une table. Mais souvent, vous ne voulez pas voir toutes les données ligne par ligne : vous voulez des **statistiques**, des **résumés**, des **totaux**.

Par exemple :
- **Combien** de clients avez-vous dans votre base ?
- Quel est le **montant total** des ventes du mois ?
- Quelle est la **moyenne** des prix de vos produits ?
- Quel est le produit le **moins cher** ? Le **plus cher** ?

Pour répondre à ces questions, SQL propose les **fonctions d'agrégation**. Ces fonctions permettent de **calculer** des valeurs à partir d'un ensemble de lignes et de retourner **une seule valeur** en résultat.

## Qu'est-ce qu'une fonction d'agrégation ?

Une fonction d'agrégation est une fonction qui :

1. **Prend en entrée** un ensemble de valeurs (une colonne de plusieurs lignes)
2. **Effectue un calcul** sur cet ensemble
3. **Retourne une seule valeur** en résultat

**Analogie :** Imaginez que vous avez un panier de pommes. Au lieu de compter chaque pomme individuellement, vous demandez : "Combien de pommes y a-t-il au total ?" La fonction d'agrégation fait ce travail pour vous.

## Les cinq fonctions d'agrégation principales

SQL Server propose cinq fonctions d'agrégation fondamentales :

| Fonction | Description | Exemple d'usage |
|----------|-------------|-----------------|
| `COUNT()` | **Compte** le nombre de lignes ou de valeurs | Nombre de clients |
| `SUM()` | **Additionne** les valeurs numériques | Total des ventes |
| `AVG()` | Calcule la **moyenne** des valeurs numériques | Prix moyen |
| `MIN()` | Trouve la **valeur minimale** | Prix le plus bas |
| `MAX()` | Trouve la **valeur maximale** | Prix le plus élevé |

Explorons chacune de ces fonctions en détail.

---

## 1. COUNT() - Compter les lignes

La fonction `COUNT()` compte le nombre de lignes ou de valeurs.

### Syntaxe

```sql
COUNT(*)              -- Compte toutes les lignes
COUNT(colonne)        -- Compte les valeurs non-NULL d'une colonne
COUNT(DISTINCT colonne) -- Compte les valeurs uniques non-NULL
```

### COUNT(*) : Compter toutes les lignes

```sql
SELECT COUNT(*) AS NombreClients
FROM Clients;
```

**Résultat possible :**
```
NombreClients
-------------
523
```

**Explication :** Cette requête compte **toutes les lignes** de la table `Clients`, y compris celles qui contiennent des valeurs NULL. C'est la forme la plus courante.

### COUNT(colonne) : Compter les valeurs non-NULL

```sql
SELECT COUNT(Email) AS ClientsAvecEmail
FROM Clients;
```

**Résultat possible :**
```
ClientsAvecEmail
----------------
487
```

**Explication :** Cette requête compte uniquement les lignes où la colonne `Email` contient une valeur (pas NULL). Si 36 clients n'ont pas d'email, ils ne sont pas comptés.

**Différence importante :**
- `COUNT(*)` compte **toutes** les lignes (même avec NULL)
- `COUNT(colonne)` compte uniquement les lignes où la colonne **n'est pas NULL**

### COUNT(DISTINCT colonne) : Compter les valeurs uniques

```sql
SELECT COUNT(DISTINCT Ville) AS NombreVillesDifferentes
FROM Clients;
```

**Résultat possible :**
```
NombreVillesDifferentes
-----------------------
47
```

**Explication :** Cette requête compte le nombre de villes **différentes** où se trouvent vos clients. Si 100 clients habitent Paris, Paris n'est compté qu'une seule fois.

### Exemple comparatif

Supposons une table `Commandes` :

| CommandeID | ClientID | Ville |
|------------|----------|-------|
| 1 | 101 | Paris |
| 2 | 102 | Lyon |
| 3 | 103 | Paris |
| 4 | 104 | NULL |
| 5 | 105 | Lyon |

```sql
-- Compte toutes les lignes
SELECT COUNT(*) FROM Commandes;
-- Résultat : 5

-- Compte les valeurs non-NULL de Ville
SELECT COUNT(Ville) FROM Commandes;
-- Résultat : 4 (la ligne avec NULL n'est pas comptée)

-- Compte les villes distinctes
SELECT COUNT(DISTINCT Ville) FROM Commandes;
-- Résultat : 2 (Paris et Lyon, NULL n'est pas compté)
```

## 2. SUM() - Additionner des valeurs

La fonction `SUM()` additionne toutes les valeurs numériques d'une colonne.

### Syntaxe

```sql
SUM(colonne_numerique)
```

### Exemple de base

```sql
SELECT SUM(MontantTotal) AS TotalVentes
FROM Commandes;
```

**Résultat possible :**
```
TotalVentes
-----------
125430.75
```

**Explication :** Cette requête additionne tous les montants de la colonne `MontantTotal` pour obtenir le chiffre d'affaires total.

### Points importants sur SUM()

**1. SUM() ignore les valeurs NULL**

```sql
-- Si certaines commandes ont un montant NULL, ils sont ignorés
SELECT SUM(Montant) FROM Commandes;
```

Les valeurs NULL ne sont pas comptées comme zéro, elles sont simplement ignorées.

**2. SUM() ne fonctionne qu'avec des nombres**

```sql
-- ❌ ERREUR : impossible d'additionner du texte
SELECT SUM(NomClient) FROM Clients;
```

**3. SUM() avec des calculs**

```sql
SELECT SUM(Quantite * PrixUnitaire) AS MontantTotal
FROM LignesCommande;
```

Vous pouvez effectuer des calculs dans SUM().

### Exemple pratique : Calculer le chiffre d'affaires

```sql
SELECT
    SUM(MontantTotal) AS ChiffreAffaires,
    COUNT(*) AS NombreCommandes
FROM Commandes
WHERE YEAR(DateCommande) = 2024;
```

**Résultat possible :**
```
ChiffreAffaires    NombreCommandes
---------------    ---------------
325000.50          847
```

## 3. AVG() - Calculer la moyenne

La fonction `AVG()` (Average) calcule la moyenne arithmétique des valeurs numériques.

### Syntaxe

```sql
AVG(colonne_numerique)
```

### Exemple de base

```sql
SELECT AVG(Prix) AS PrixMoyen
FROM Produits;
```

**Résultat possible :**
```
PrixMoyen
---------
45.67
```

**Explication :** Cette requête calcule le prix moyen de tous les produits.

### Comment AVG() fonctionne

`AVG()` équivaut à : **somme des valeurs / nombre de valeurs non-NULL**

```sql
-- Ces deux requêtes donnent le même résultat
SELECT AVG(Prix) FROM Produits;

SELECT SUM(Prix) / COUNT(Prix) FROM Produits;
```

### Points importants sur AVG()

**1. AVG() ignore les valeurs NULL**

Si une ligne a une valeur NULL, elle n'est **ni comptée ni incluse** dans le calcul de la moyenne.

**Exemple :** Table avec 5 produits : 10, 20, NULL, 30, 40

```sql
SELECT AVG(Prix) FROM Produits;
-- Résultat : 25 (calculé comme : (10+20+30+40) / 4, pas / 5)
```

**2. AVG() retourne un type décimal**

```sql
SELECT AVG(Quantite) FROM Commandes;
-- Peut retourner 12.5 même si Quantite est un INT
```

**3. Arrondir la moyenne**

```sql
-- Arrondir à 2 décimales
SELECT ROUND(AVG(Prix), 2) AS PrixMoyen
FROM Produits;
```

### Exemple pratique : Panier moyen

```sql
SELECT
    COUNT(*) AS NombreCommandes,
    SUM(MontantTotal) AS TotalVentes,
    AVG(MontantTotal) AS PanierMoyen
FROM Commandes
WHERE YEAR(DateCommande) = 2024;
```

**Résultat possible :**
```
NombreCommandes  TotalVentes  PanierMoyen
---------------  -----------  -----------
847              325000.50    383.73
```

**Interprétation :** En moyenne, chaque commande vaut 383,73€.

## 4. MIN() - Trouver la valeur minimale

La fonction `MIN()` retourne la plus petite valeur d'une colonne.

### Syntaxe

```sql
MIN(colonne)
```

### Exemple avec des nombres

```sql
SELECT MIN(Prix) AS PrixLePlusBas
FROM Produits;
```

**Résultat possible :**
```
PrixLePlusBas
-------------
5.99
```

**Explication :** Cette requête trouve le produit le moins cher.

### MIN() fonctionne aussi avec du texte

```sql
SELECT MIN(NomClient) AS PremierClientAlphabetique
FROM Clients;
```

**Résultat possible :**
```
PremierClientAlphabetique
-------------------------
Alain Dupont
```

**Explication :** `MIN()` sur du texte retourne la valeur qui vient **en premier** dans l'ordre alphabétique.

### MIN() fonctionne avec les dates

```sql
SELECT MIN(DateCommande) AS PremiereDateCommande
FROM Commandes;
```

**Résultat possible :**
```
PremiereDateCommande
--------------------
2020-01-15
```

**Explication :** Retourne la date de commande la plus ancienne.

### Exemple pratique : Produit le moins cher par catégorie

```sql
SELECT
    Categorie,
    MIN(Prix) AS PrixMinimum
FROM Produits
GROUP BY Categorie;
```

**Résultat possible :**
```
Categorie        PrixMinimum
--------------   -----------
Électronique     15.99
Vêtements        8.50
Alimentation     2.25
```

---

## 5. MAX() - Trouver la valeur maximale

La fonction `MAX()` retourne la plus grande valeur d'une colonne.

### Syntaxe

```sql
MAX(colonne)
```

### Exemple avec des nombres

```sql
SELECT MAX(Prix) AS PrixLePlusEleve
FROM Produits;
```

**Résultat possible :**
```
PrixLePlusEleve
---------------
1299.99
```

**Explication :** Cette requête trouve le produit le plus cher.

### MAX() avec du texte

```sql
SELECT MAX(NomClient) AS DernierClientAlphabetique
FROM Clients;
```

**Résultat possible :**
```
DernierClientAlphabetique
-------------------------
Zoé Martin
```

**Explication :** `MAX()` sur du texte retourne la valeur qui vient **en dernier** dans l'ordre alphabétique.

### MAX() avec les dates

```sql
SELECT MAX(DateCommande) AS DerniereDateCommande
FROM Commandes;
```

**Résultat possible :**
```
DerniereDateCommande
--------------------
2024-11-15
```

**Explication :** Retourne la date de commande la plus récente.

### Exemple pratique : Étendue des prix

```sql
SELECT
    MIN(Prix) AS PrixMinimum,
    MAX(Prix) AS PrixMaximum,
    MAX(Prix) - MIN(Prix) AS Etendue
FROM Produits;
```

**Résultat possible :**
```
PrixMinimum  PrixMaximum  Etendue
-----------  -----------  -------
5.99         1299.99      1294.00
```

## Combiner plusieurs fonctions d'agrégation

Vous pouvez utiliser **plusieurs fonctions d'agrégation** dans la même requête.

### Exemple : Rapport complet sur les ventes

```sql
SELECT
    COUNT(*) AS NombreCommandes,
    SUM(MontantTotal) AS ChiffreAffaires,
    AVG(MontantTotal) AS PanierMoyen,
    MIN(MontantTotal) AS CommandeMinimale,
    MAX(MontantTotal) AS CommandeMaximale
FROM Commandes
WHERE YEAR(DateCommande) = 2024;
```

**Résultat possible :**
```
NombreCommandes  ChiffreAffaires  PanierMoyen  CommandeMinimale  CommandeMaximale
---------------  ---------------  -----------  ----------------  ----------------
847              325000.50        383.73       12.50             2500.00
```

**Interprétation :**
- 847 commandes ont été passées en 2024
- Le chiffre d'affaires total est de 325 000,50€
- Le panier moyen est de 383,73€
- La plus petite commande était de 12,50€
- La plus grosse commande était de 2 500€

## Gestion des valeurs NULL

### Comportement général

Toutes les fonctions d'agrégation (sauf `COUNT(*)`) **ignorent** les valeurs NULL.

### Exemple illustratif

Table `Produits` :

| ProduitID | NomProduit | Prix |
|-----------|------------|------|
| 1 | Stylo | 2.50 |
| 2 | Cahier | 5.00 |
| 3 | Trousse | NULL |
| 4 | Règle | 1.50 |

```sql
SELECT
    COUNT(*) AS TotalLignes,           -- 4
    COUNT(Prix) AS PrixNonNulls,       -- 3
    SUM(Prix) AS Total,                -- 9.00
    AVG(Prix) AS Moyenne,              -- 3.00 (9/3, pas 9/4)
    MIN(Prix) AS Minimum,              -- 1.50
    MAX(Prix) AS Maximum               -- 5.00
FROM Produits;
```

**Résultat :**
```
TotalLignes  PrixNonNulls  Total  Moyenne  Minimum  Maximum
-----------  ------------  -----  -------  -------  -------
4            3             9.00   3.00     1.50     5.00
```

### Traiter les NULL comme zéro

Si vous voulez traiter les NULL comme des zéros, utilisez `ISNULL()` ou `COALESCE()` :

```sql
SELECT
    AVG(Prix) AS MoyenneSansNull,           -- NULL ignorés
    AVG(ISNULL(Prix, 0)) AS MoyenneAvecZero -- NULL = 0
FROM Produits;
```

**Résultat avec les données ci-dessus :**
```
MoyenneSansNull  MoyenneAvecZero
---------------  ---------------
3.00             2.25  (9.00 / 4)
```

## Utilisation avec WHERE

Vous pouvez combiner les fonctions d'agrégation avec la clause `WHERE` pour filtrer les données **avant** l'agrégation.

### Exemple : Ventes d'un mois spécifique

```sql
SELECT
    COUNT(*) AS NombreVentes,
    SUM(Montant) AS TotalVentes,
    AVG(Montant) AS MoyenneVentes
FROM Commandes
WHERE YEAR(DateCommande) = 2024
  AND MONTH(DateCommande) = 11;
```

### Ordre d'exécution

```
1. FROM      → Identifier la table Commandes
2. WHERE     → Filtrer les commandes de novembre 2024
3. SELECT    → Calculer les agrégations sur les lignes filtrées
```

Le `WHERE` s'applique **avant** l'agrégation.

## Limitations importantes

### 1. Impossible de mélanger colonnes normales et agrégations

```sql
-- ❌ ERREUR : ProduitID n'est pas agrégé
SELECT
    ProduitID,       -- Colonne normale
    AVG(Prix)        -- Fonction d'agrégation
FROM Produits;
```

**Pourquoi ?** Si AVG(Prix) retourne une seule valeur (ex: 45.67), quel ProduitID afficher ? Il y en a plusieurs !

**Solution :** Utiliser `GROUP BY` (que nous verrons dans la section suivante).

### 2. Les agrégations ne peuvent pas être dans WHERE

```sql
-- ❌ ERREUR : impossible d'utiliser AVG() dans WHERE
SELECT *
FROM Produits
WHERE Prix > AVG(Prix);
```

**Solution :** Utiliser une sous-requête ou `HAVING` (avec GROUP BY).

### 3. COUNT(*) vs COUNT(colonne)

Faites attention à la différence :

```sql
-- Compte toutes les lignes
SELECT COUNT(*) FROM Clients;  -- 1000

-- Compte uniquement les emails non-NULL
SELECT COUNT(Email) FROM Clients;  -- 950
```

## Alias et formatage des résultats

### Utiliser des alias clairs

```sql
SELECT
    COUNT(*) AS [Nombre de produits],
    AVG(Prix) AS [Prix moyen (€)],
    MAX(Prix) AS [Prix maximum (€)]
FROM Produits;
```

**Résultat :**
```
Nombre de produits  Prix moyen (€)  Prix maximum (€)
------------------  --------------  ----------------
245                 45.67           1299.99
```

### Formater les nombres

```sql
SELECT
    COUNT(*) AS NombreProduits,
    FORMAT(AVG(Prix), 'N2') AS PrixMoyenFormate,
    CAST(AVG(Prix) AS DECIMAL(10,2)) AS PrixMoyenArrondi
FROM Produits;
```

**Résultat :**
```
NombreProduits  PrixMoyenFormate  PrixMoyenArrondi
--------------  ----------------  ----------------
245             45.67             45.67
```

## Cas d'usage pratiques

### 1. Tableau de bord commercial

```sql
SELECT
    'Statistiques de ventes 2024' AS Rapport,
    COUNT(DISTINCT ClientID) AS ClientsUniques,
    COUNT(*) AS TotalCommandes,
    SUM(MontantTotal) AS ChiffreAffaires,
    AVG(MontantTotal) AS PanierMoyen,
    MIN(DateCommande) AS PremiereVente,
    MAX(DateCommande) AS DerniereVente
FROM Commandes
WHERE YEAR(DateCommande) = 2024;
```

### 2. Analyse de l'inventaire

```sql
SELECT
    COUNT(*) AS NombreProduits,
    COUNT(DISTINCT Categorie) AS NombreCategories,
    SUM(Stock * PrixUnitaire) AS ValeurStock,
    AVG(Stock) AS StockMoyen,
    MIN(Stock) AS StockMinimum,
    MAX(Stock) AS StockMaximum
FROM Produits
WHERE Actif = 1;
```

### 3. Analyse RH : Statistiques sur les salaires

```sql
SELECT
    COUNT(*) AS NombreEmployes,
    AVG(Salaire) AS SalaireMoyen,
    MIN(Salaire) AS SalaireMinimum,
    MAX(Salaire) AS SalaireMaximum,
    MAX(Salaire) - MIN(Salaire) AS EcartSalarial,
    SUM(Salaire) AS MasseSalariale
FROM Employes
WHERE Actif = 1;
```

### 4. Analyse de satisfaction client

```sql
SELECT
    COUNT(*) AS NombreAvis,
    AVG(Note) AS NoteMoyenne,
    MIN(Note) AS NotePlusBasse,
    MAX(Note) AS NotePlusHaute,
    COUNT(CASE WHEN Note >= 4 THEN 1 END) AS AvisPositifs,
    COUNT(CASE WHEN Note <= 2 THEN 1 END) AS AvisNegatifs
FROM Avis
WHERE YEAR(DateAvis) = 2024;
```

## Différences entre les fonctions

### Tableau récapitulatif

| Fonction | Type de données accepté | Ignore NULL ? | Résultat unique ? | Usage typique |
|----------|------------------------|---------------|-------------------|---------------|
| `COUNT(*)` | Tous | Non | Oui | Compter des lignes |
| `COUNT(col)` | Tous | Oui | Oui | Compter des valeurs |
| `SUM()` | Numérique uniquement | Oui | Oui | Totaux, CA |
| `AVG()` | Numérique uniquement | Oui | Oui | Moyennes |
| `MIN()` | Numérique, texte, date | Oui | Oui | Valeur minimale |
| `MAX()` | Numérique, texte, date | Oui | Oui | Valeur maximale |

### Compatibilité des types

```sql
-- ✅ Fonctionne : MIN/MAX sur différents types
SELECT MIN(Prix) FROM Produits;           -- Numérique
SELECT MIN(NomClient) FROM Clients;       -- Texte
SELECT MIN(DateCommande) FROM Commandes;  -- Date

-- ❌ Erreur : SUM/AVG uniquement sur numérique
SELECT SUM(NomClient) FROM Clients;       -- ERREUR
SELECT AVG(DateCommande) FROM Commandes;  -- ERREUR
```

## Bonnes pratiques

### ✅ À faire

1. **Utiliser des alias explicites**
```sql
SELECT COUNT(*) AS NombreClients  -- ✅ Clair
-- Mieux que :
SELECT COUNT(*)                    -- ❌ Peu clair
```

2. **Filtrer avec WHERE avant d'agréger**
```sql
-- ✅ Efficace : filtre puis agrège
SELECT AVG(Prix)
FROM Produits
WHERE Actif = 1;
```

3. **Documenter les calculs complexes**
```sql
SELECT
    SUM(Quantite * PrixUnitaire) AS MontantTotal,
    -- Calcule le CA en multipliant quantité par prix unitaire
    SUM(Quantite * PrixUnitaire * 0.2) AS TVA
FROM LignesCommande;
```

4. **Arrondir les moyennes pour la lisibilité**
```sql
SELECT ROUND(AVG(Prix), 2) AS PrixMoyen
FROM Produits;
```

### ❌ À éviter

1. **Mélanger colonnes et agrégations sans GROUP BY**
```sql
-- ❌ ERREUR
SELECT ClientID, COUNT(*)
FROM Commandes;
```

2. **Oublier que NULL est ignoré**
```sql
-- ⚠️ Attention : peut donner des résultats inattendus
SELECT AVG(Remise) FROM Commandes;
-- Si beaucoup de NULL, la moyenne peut être trompeuse
```

3. **Utiliser COUNT(*) quand COUNT(colonne) est plus approprié**
```sql
-- Si vous voulez compter les emails renseignés :
SELECT COUNT(Email) FROM Clients;  -- ✅
-- Pas :
SELECT COUNT(*) FROM Clients;      -- ❌ Compte tout
```

## Points de vigilance

### 1. Division par zéro

```sql
-- ⚠️ Peut causer une erreur si aucun produit
SELECT
    SUM(Prix) / COUNT(*) AS PrixMoyen
FROM Produits
WHERE Categorie = 'Inexistante';
```

**Solution :** Utiliser `NULLIF` ou vérifier avant :
```sql
SELECT
    CASE
        WHEN COUNT(*) > 0 THEN SUM(Prix) / COUNT(*)
        ELSE 0
    END AS PrixMoyen
FROM Produits;
```

### 2. Précision des calculs

```sql
-- AVG sur des INT peut tronquer
DECLARE @Table TABLE (Valeur INT);
INSERT INTO @Table VALUES (1), (2);

SELECT AVG(Valeur) FROM @Table;  -- Résultat : 1, pas 1.5 !

-- Solution : convertir en DECIMAL
SELECT AVG(CAST(Valeur AS DECIMAL(10,2))) FROM @Table;  -- 1.50
```

### 3. Performance sur de grandes tables

Les fonctions d'agrégation sur des millions de lignes peuvent être coûteuses. Utilisez :
- Des index appropriés
- Des filtres WHERE efficaces
- Des tables pré-agrégées (pour les rapports)

## Résumé

| Fonction | Syntaxe | Exemple | Résultat |
|----------|---------|---------|----------|
| **COUNT(*)** | `COUNT(*)` | `SELECT COUNT(*) FROM Clients` | Nombre total de lignes |
| **COUNT(col)** | `COUNT(colonne)` | `SELECT COUNT(Email) FROM Clients` | Nombre de valeurs non-NULL |
| **SUM()** | `SUM(colonne)` | `SELECT SUM(Montant) FROM Ventes` | Somme totale |
| **AVG()** | `AVG(colonne)` | `SELECT AVG(Prix) FROM Produits` | Moyenne |
| **MIN()** | `MIN(colonne)` | `SELECT MIN(Prix) FROM Produits` | Valeur minimale |
| **MAX()** | `MAX(colonne)` | `SELECT MAX(Prix) FROM Produits` | Valeur maximale |

### Points clés à retenir

1. Les fonctions d'agrégation retournent **une seule valeur** à partir de plusieurs lignes
2. Elles **ignorent les NULL** (sauf `COUNT(*)`)
3. `COUNT(*)` compte toutes les lignes, `COUNT(colonne)` compte les non-NULL
4. `SUM()` et `AVG()` ne fonctionnent qu'avec des **nombres**
5. `MIN()` et `MAX()` fonctionnent avec nombres, textes et dates
6. Utilisez `WHERE` pour filtrer **avant** l'agrégation
7. Vous ne pouvez pas mélanger colonnes normales et agrégations sans `GROUP BY`

## Prochaine étape

Par exemple, au lieu de calculer le chiffre d'affaires total, vous pourriez calculer le chiffre d'affaires **par vendeur**, **par région**, ou **par mois**.
