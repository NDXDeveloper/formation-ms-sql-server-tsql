# 3.1.3 Alias de colonnes (AS)

## Introduction

Lorsque vous affichez des données avec `SELECT`, les noms de colonnes dans les résultats sont, par défaut, les **noms exacts** des colonnes de la table. Mais parfois, ces noms ne sont pas assez clairs ou adaptés pour votre usage.

Les **alias** permettent de renommer temporairement les colonnes dans les résultats de votre requête, sans modifier la structure réelle de la table.

**Analogie** : C'est comme mettre une étiquette temporaire sur une boîte. La boîte garde son nom d'origine, mais pour cette occasion, vous l'appelez autrement pour plus de clarté.

---

## Qu'est-ce qu'un alias ?

Un **alias** est un nom alternatif, temporaire, que vous donnez à une colonne (ou une table, mais nous verrons cela plus tard) dans le contexte d'une requête.

- L'alias n'existe **que pour cette requête**
- Il ne modifie **pas** la structure de la table
- Il rend les résultats plus **lisibles** et **compréhensibles**

---

## Syntaxe avec AS

### Forme standard

```sql
SELECT nom_colonne AS nom_alias
FROM nom_table
```

Le mot-clé `AS` signifie "également appelé" ou "aussi connu sous le nom de".

### Exemple simple

**Sans alias** :
```sql
SELECT Prenom, Nom
FROM Clients
```

**Résultat** :

| Prenom | Nom    |
|--------|--------|
| Sophie | Martin |
| Pierre | Dubois |

**Avec alias** :
```sql
SELECT Prenom AS PrenomClient, Nom AS NomClient
FROM Clients
```

**Résultat** :

| PrenomClient | NomClient |
|--------------|-----------|
| Sophie       | Martin    |
| Pierre       | Dubois    |

Les colonnes sont affichées avec les nouveaux noms !

---

## Syntaxe sans AS (optionnelle)

En T-SQL, le mot-clé `AS` est **optionnel**. Vous pouvez simplement écrire :

```sql
SELECT Prenom PrenomClient, Nom NomClient
FROM Clients
```

Cette syntaxe produit exactement le même résultat.

### Quelle syntaxe choisir ?

| Avec AS | Sans AS |
|---------|---------|
| `SELECT Prenom AS PrenomClient` | `SELECT Prenom PrenomClient` |
| ✅ Plus explicite et lisible | ⚠️ Plus concis mais moins clair |
| ✅ Recommandé pour les débutants | ⚠️ Peut prêter à confusion |
| ✅ Standard SQL | ✅ Accepté en T-SQL |

**Recommandation** : Utilisez `AS` pour plus de clarté, surtout au début. Avec l'expérience, vous pourrez choisir selon votre préférence.

---

## Pourquoi utiliser des alias ?

### 1. **Rendre les noms plus explicites**

Les noms de colonnes dans la base peuvent être techniques ou abrégés.

**Exemple** :
```sql
SELECT
    cli_id AS IdentifiantClient,
    cli_prn AS Prenom,
    cli_nm AS Nom,
    cli_dt_insc AS DateInscription
FROM t_clients
```

Au lieu d'afficher `cli_id`, `cli_prn`, `cli_nm`, vous obtenez des noms clairs et compréhensibles.

---

### 2. **Adapter les noms à la langue de l'utilisateur**

Si votre table a des noms en anglais mais que vous présentez les données à des utilisateurs francophones :

```sql
SELECT
    FirstName AS Prenom,
    LastName AS Nom,
    BirthDate AS DateNaissance,
    City AS Ville
FROM Employees
```

---

### 3. **Simplifier les noms composés**

Parfois, les noms de colonnes suivent une convention de nommage longue :

```sql
SELECT
    Customer_First_Name AS Prenom,
    Customer_Last_Name AS Nom,
    Customer_Email_Address AS Email
FROM Customers
```

---

### 4. **Clarifier les calculs**

Lorsque vous effectuez des calculs (nous verrons cela plus en détail plus tard), les alias sont essentiels pour nommer le résultat :

```sql
SELECT
    NomProduit,
    Prix,
    Quantite,
    Prix * Quantite AS MontantTotal
FROM Produits
```

**Résultat** :

| NomProduit | Prix | Quantite | MontantTotal |
|------------|------|----------|--------------|
| Ordinateur | 800  | 2        | 1600         |
| Souris     | 25   | 5        | 125          |

Sans l'alias `MontantTotal`, la colonne s'afficherait avec un nom peu clair comme `(No column name)` ou la formule complète.

---

### 5. **Éviter les doublons de noms**

Lorsque vous combinez plusieurs tables (nous verrons les jointures plus tard), deux colonnes peuvent avoir le même nom :

```sql
SELECT
    Clients.Nom AS NomClient,
    Employes.Nom AS NomEmploye
FROM Clients, Employes
```

Les alias permettent de différencier clairement les deux colonnes `Nom`.

---

## Alias avec espaces et caractères spéciaux

### Le problème

Par défaut, les noms d'alias ne peuvent pas contenir d'espaces ou de caractères spéciaux.

**❌ Ceci ne fonctionnera pas** :
```sql
SELECT Prenom AS Prénom du Client
FROM Clients
```

### La solution : Utiliser des crochets [ ] ou des guillemets " "

Pour créer un alias contenant des espaces ou des caractères accentués, entourez-le de **crochets** (syntaxe T-SQL) :

```sql
SELECT
    Prenom AS [Prénom du Client],
    Nom AS [Nom de Famille],
    Email AS [Adresse Email]
FROM Clients
```

**Résultat** :

| Prénom du Client | Nom de Famille | Adresse Email         |
|------------------|----------------|-----------------------|
| Sophie           | Martin         | sophie.martin@mail.fr |

Vous pouvez aussi utiliser des **guillemets doubles** (standard SQL) :

```sql
SELECT
    Prenom AS "Prénom du Client",
    Nom AS "Nom de Famille"
FROM Clients
```

**Note** : En T-SQL, les crochets `[ ]` sont plus couramment utilisés.

---

## Exemples pratiques

### Exemple 1 : Table Produits

**Sans alias** :
```sql
SELECT NomProduit, Prix, Stock
FROM Produits
```

**Avec alias** :
```sql
SELECT
    NomProduit AS Produit,
    Prix AS [Prix Unitaire],
    Stock AS [Quantité en Stock]
FROM Produits
```

**Résultat** :

| Produit    | Prix Unitaire | Quantité en Stock |
|------------|---------------|-------------------|
| Ordinateur | 800.00        | 15                |
| Clavier    | 45.00         | 50                |
| Souris     | 25.00         | 100               |

---

### Exemple 2 : Table Employes

```sql
SELECT
    EmployeID AS [N° Employé],
    Prenom AS Prénom,
    Nom AS [Nom de Famille],
    Poste AS Fonction,
    Salaire AS [Salaire Mensuel]
FROM Employes
```

---

### Exemple 3 : Combinaison de colonnes (concaténation)

Vous pouvez créer une nouvelle colonne en combinant plusieurs colonnes existantes :

```sql
SELECT
    Prenom + ' ' + Nom AS [Nom Complet],
    Email
FROM Clients
```

**Résultat** :

| Nom Complet   | Email                 |
|---------------|-----------------------|
| Sophie Martin | sophie.martin@mail.fr |
| Pierre Dubois | pierre.dubois@mail.fr |

L'opérateur `+` en T-SQL sert à concaténer (coller ensemble) des chaînes de caractères.

> ⚠️ **Attention au NULL** — Avec l'opérateur `+`, si **l'une** des colonnes vaut `NULL`, tout le résultat devient `NULL` (un client sans prénom n'aurait donc aucun « Nom Complet »). La fonction `CONCAT(Prenom, ' ', Nom)` évite ce piège en traitant les `NULL` comme des chaînes vides. Nous y reviendrons en section 3.2.5.

---

## Cas d'usage avancés

### Alias pour des expressions complexes

Les alias sont particulièrement utiles pour nommer des expressions ou des fonctions :

```sql
SELECT
    NomProduit,
    Prix,
    Prix * 0.20 AS Remise20Pourcent,
    Prix * 0.80 AS PrixApresRemise
FROM Produits
```

**Résultat** :

| NomProduit | Prix   | Remise20Pourcent | PrixApresRemise |
|------------|--------|------------------|-----------------|
| Ordinateur | 800.00 | 160.00           | 640.00          |
| Clavier    | 45.00  | 9.00             | 36.00           |

---

### Alias pour des fonctions d'agrégation

Lorsque vous utilisez des fonctions comme `COUNT`, `SUM`, `AVG` (nous les verrons en détail plus tard), les alias rendent les résultats compréhensibles :

```sql
SELECT
    COUNT(*) AS [Nombre de Clients],
    AVG(Salaire) AS [Salaire Moyen]
FROM Employes
```

**Résultat** :

| Nombre de Clients | Salaire Moyen |
|-------------------|---------------|
| 150               | 3250.50       |

Sans alias, vous obtiendriez des noms de colonnes peu parlants.

---

## Bonnes pratiques

### ✅ À faire

1. **Utilisez des noms clairs et explicites**
   ```sql
   SELECT Prix * Quantite AS MontantTotal  -- ✅ Bon
   ```

2. **Adoptez une convention de nommage cohérente**
   - PascalCase : `MontantTotal`, `PrixUnitaire`
   - snake_case : `montant_total`, `prix_unitaire`
   - Choisissez-en une et restez cohérent

3. **Utilisez AS pour la clarté**
   ```sql
   SELECT Prenom AS PrenomClient  -- ✅ Clair
   ```

4. **Évitez les mots réservés SQL**
   Ne nommez pas vos alias avec des mots-clés SQL comme `SELECT`, `FROM`, `WHERE`, etc.

---

### ❌ À éviter

1. **Alias trop courts ou cryptiques**
   ```sql
   SELECT Prenom AS P  -- ❌ Pas assez explicite
   ```

2. **Alias inutiles qui n'apportent rien**
   ```sql
   SELECT Prenom AS Prenom  -- ❌ Inutile
   ```

3. **Espaces sans crochets**
   ```sql
   SELECT Prenom AS Prenom Client  -- ❌ Erreur de syntaxe
   ```

4. **Alias incohérents dans une même requête**
   ```sql
   SELECT
       Prenom AS prenomClient,
       Nom AS NOM_CLIENT,
       Email AS e  -- ❌ Styles mélangés
   ```

---

## Points importants à retenir

### 1. Portée de l'alias

L'alias n'existe que dans les **résultats** de la requête. Vous ne pouvez pas l'utiliser dans la clause `WHERE` de la même requête :

**❌ Ceci ne fonctionne pas** :
```sql
SELECT
    Prix * Quantite AS MontantTotal
FROM Commandes
WHERE MontantTotal > 1000  -- ❌ Erreur : MontantTotal n'existe pas encore
```

**✅ Solution** : Répétez l'expression ou utilisez une sous-requête / CTE (concepts avancés)
```sql
SELECT
    Prix * Quantite AS MontantTotal
FROM Commandes
WHERE Prix * Quantite > 1000  -- ✅ Fonctionne
```

---

### 2. Utilisation dans ORDER BY

**Bonne nouvelle** : Vous pouvez utiliser un alias dans la clause `ORDER BY` :

```sql
SELECT
    Prenom + ' ' + Nom AS NomComplet
FROM Clients
ORDER BY NomComplet  -- ✅ Fonctionne !
```

---

### 3. Les alias ne modifient pas la base de données

Rappelez-vous : un alias est **temporaire** et ne concerne que l'affichage des résultats. La table d'origine reste inchangée.

## Résumé

### Ce qu'il faut retenir

1. **Un alias** = un nom alternatif temporaire pour une colonne

2. **Syntaxe** : `SELECT colonne AS alias` (ou sans `AS`)

3. **Utilisations principales** :
   - Rendre les noms plus clairs
   - Traduire les noms
   - Nommer des calculs ou expressions
   - Éviter les doublons de noms

4. **Pour les espaces** : Utiliser des crochets `[Nom avec espaces]`

5. **Bonne pratique** : Utiliser `AS` et des noms explicites

6. **Limitation** : Ne peut pas être utilisé dans `WHERE` de la même requête

---

## Exemple complet récapitulatif

Voici une requête qui illustre plusieurs usages d'alias :

```sql
SELECT
    ProduitID AS [N° Produit],
    NomProduit AS Produit,
    Prix AS [Prix Unitaire (€)],
    Stock AS [En Stock],
    Prix * 1.20 AS [Prix TTC],
    CASE
        WHEN Stock > 50 THEN 'Disponible'
        WHEN Stock > 0 THEN 'Stock Limité'
        ELSE 'Rupture'
    END AS Disponibilité
FROM Produits
ORDER BY [Prix Unitaire (€)] DESC
```

Cette requête montre comment les alias rendent les résultats immédiatement compréhensibles pour l'utilisateur final !
