# 2.2.1 CREATE DATABASE

## Introduction

Une base de données est un conteneur qui regroupe l'ensemble de vos tables, vues, procédures stockées et autres objets SQL Server. Avant de pouvoir créer des tables et manipuler des données, vous devez d'abord créer une base de données.

La commande `CREATE DATABASE` est l'instruction SQL qui permet de créer une nouvelle base de données sur votre instance SQL Server.

## Syntaxe de Base

La forme la plus simple de la commande est :

```sql
CREATE DATABASE NomDeLaBase;
```

Cette syntaxe minimaliste crée une base de données avec les paramètres par défaut de SQL Server.

## Exemple Simple

Imaginons que vous souhaitiez créer une base de données pour gérer une bibliothèque :

```sql
CREATE DATABASE Bibliotheque;
```

Après l'exécution de cette commande, une nouvelle base de données nommée "Bibliotheque" est créée sur votre serveur SQL Server.

## Vérification de la Création

Pour vérifier que votre base de données a bien été créée, vous pouvez :

1. **Dans SQL Server Management Studio (SSMS)** : actualiser la liste des bases de données dans l'explorateur d'objets
2. **Avec une requête SQL** :

```sql
SELECT name
FROM sys.databases
WHERE name = 'Bibliotheque';
```

## Utilisation de la Base de Données

Une fois la base de données créée, vous devez indiquer à SQL Server que vous souhaitez l'utiliser pour vos prochaines opérations. Pour cela, utilisez la commande `USE` :

```sql
USE Bibliotheque;
```

À partir de ce moment, toutes vos commandes SQL (création de tables, insertion de données, etc.) s'appliqueront à cette base de données.

## Conventions de Nommage

Il est important de respecter quelques bonnes pratiques lors du choix du nom de votre base de données :

- **Utilisez des noms significatifs** : le nom doit refléter le contenu ou l'objectif de la base (ex: `GestionStock`, `RessourcesHumaines`)
- **Évitez les espaces** : préférez `GestionStock` à `Gestion Stock`. Si vous devez utiliser des espaces, vous devrez entourer le nom de crochets : `[Gestion Stock]`
- **Évitez les caractères spéciaux** : restez sur des lettres, chiffres et underscores (_)
- **Soyez cohérent** : choisissez une convention (PascalCase, snake_case) et respectez-la dans tout votre projet

## Exemples de Noms de Bases de Données

```sql
-- Style PascalCase (recommandé)
CREATE DATABASE GestionCommerciale;
CREATE DATABASE RessourcesHumaines;
CREATE DATABASE InventaireMagasin;

-- Style snake_case
CREATE DATABASE gestion_commerciale;
CREATE DATABASE ressources_humaines;
CREATE DATABASE inventaire_magasin;
```

## Syntaxe Avancée (Aperçu)

Bien que la syntaxe simple soit suffisante pour débuter, sachez que `CREATE DATABASE` offre de nombreuses options avancées pour contrôler :

- L'emplacement des fichiers de données et de logs
- La taille initiale et la croissance automatique des fichiers
- Le mode de récupération
- Les options de collation (tri et comparaison de chaînes)

Exemple avec quelques options :

```sql
CREATE DATABASE MaBaseAvancee
ON PRIMARY
(
    NAME = 'MaBaseAvancee_Data',
    FILENAME = 'C:\SQLData\MaBaseAvancee.mdf',
    SIZE = 10MB,
    MAXSIZE = 100MB,
    FILEGROWTH = 5MB
)
LOG ON
(
    NAME = 'MaBaseAvancee_Log',
    FILENAME = 'C:\SQLData\MaBaseAvancee_Log.ldf',
    SIZE = 5MB,
    MAXSIZE = 50MB,
    FILEGROWTH = 5MB
);
```

**Note pour les débutants** : ne vous inquiétez pas si cette syntaxe vous semble complexe. Dans la plupart des cas, la syntaxe simple suffit amplement. SQL Server gère automatiquement les détails techniques.

## Points Importants à Retenir

1. **Permissions requises** : pour créer une base de données, vous devez avoir les permissions nécessaires sur le serveur (généralement, vous devez être administrateur ou avoir le rôle `dbcreator`)

2. **Unicité du nom** : vous ne pouvez pas créer deux bases de données avec le même nom sur la même instance SQL Server

3. **Bases système** : SQL Server possède des bases de données système — **master**, **model**, **msdb**, **tempdb** (plus la base cachée **Resource**) — qui ne doivent jamais être supprimées. Vos bases de données utilisateur sont créées en plus de ces bases système

4. **Modèle (model)** : quand vous créez une nouvelle base de données, SQL Server utilise la base `model` comme modèle. Votre nouvelle base hérite donc des paramètres de `model`

## Suppression d'une Base de Données

Si vous avez besoin de supprimer une base de données (attention, cette opération est irréversible !), utilisez :

```sql
DROP DATABASE NomDeLaBase;
```

Exemple :

```sql
DROP DATABASE Bibliotheque;
```

**⚠️ ATTENTION** : cette commande supprime définitivement la base de données et toutes les données qu'elle contient. Utilisez-la avec précaution !

## Créer ou supprimer « seulement si besoin »

Pour éviter une erreur lorsque la base existe déjà (ou, au contraire, n'existe pas), on teste son existence au préalable.

```sql
-- Supprimer la base uniquement si elle existe (DROP ... IF EXISTS, depuis SQL Server 2016)
DROP DATABASE IF EXISTS Bibliotheque;

-- ⚠️ Il n'existe PAS de « CREATE DATABASE IF NOT EXISTS » en T-SQL
--    (contrairement à MySQL). On teste donc explicitement avant de créer :
IF NOT EXISTS (SELECT 1 FROM sys.databases WHERE name = 'Bibliotheque')
    CREATE DATABASE Bibliotheque;
```

> 💡 Ce motif `IF NOT EXISTS (...)` / `IF EXISTS (...)` est très courant dans les scripts de déploiement, qui doivent pouvoir être ré-exécutés sans erreur (on parle de scripts *idempotents*).

## Résumé

- `CREATE DATABASE` crée une nouvelle base de données
- La syntaxe minimale est : `CREATE DATABASE NomDeLaBase;`
- Utilisez `USE NomDeLaBase;` pour sélectionner la base de données
- Choisissez des noms clairs et cohérents
- `DROP DATABASE` supprime une base de données (ATTENTION : irréversible)

## Exemple Complet

Voici un exemple complet montrant la création d'une base de données et sa sélection :

```sql
-- Création de la base de données
CREATE DATABASE EcoleMusique;

-- Vérification de la création
SELECT name
FROM sys.databases
WHERE name = 'EcoleMusique';

-- Sélection de la base pour l'utiliser
USE EcoleMusique;

-- Vous êtes maintenant prêt à créer des tables dans cette base
-- (nous verrons cela dans la section suivante : CREATE TABLE)
```

Vous savez maintenant créer une base de données ! La prochaine étape sera de créer des tables à l'intérieur de cette base pour y stocker vos données.
