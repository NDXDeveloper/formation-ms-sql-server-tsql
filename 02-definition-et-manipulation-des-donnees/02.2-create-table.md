# 2.2.2 CREATE TABLE (Syntaxe de base)

## Introduction

Une **table** est la structure fondamentale d'une base de données relationnelle. Vous pouvez imaginer une table comme un tableau Excel : elle contient des **colonnes** (les en-têtes) et des **lignes** (les enregistrements de données).

Par exemple, une table "Clients" pourrait contenir :
- Des colonnes : IdClient, Nom, Prenom, Email, DateInscription
- Des lignes : chaque ligne représente un client spécifique

La commande `CREATE TABLE` permet de créer une nouvelle table dans votre base de données.

## Syntaxe de Base

Voici la structure générale de la commande :

```sql
CREATE TABLE NomTable
(
    NomColonne1 TypeDonnées,
    NomColonne2 TypeDonnées,
    NomColonne3 TypeDonnées
);
```

**Explications :**
- `NomTable` : le nom que vous donnez à votre table
- `NomColonne` : le nom de chaque colonne
- `TypeDonnées` : le type de données que la colonne peut contenir (nombre, texte, date, etc.)

## Premier Exemple Simple

Créons une table pour stocker des informations sur des livres :

```sql
CREATE TABLE Livres
(
    Titre VARCHAR(100),
    Auteur VARCHAR(100),
    AnneePublication INT,
    Prix DECIMAL(10, 2)
);
```

**Analyse de cet exemple :**
- `Titre` : une colonne de texte pouvant contenir jusqu'à 100 caractères
- `Auteur` : une colonne de texte pouvant contenir jusqu'à 100 caractères
- `AnneePublication` : une colonne de nombres entiers
- `Prix` : une colonne de nombres décimaux (10 chiffres au total, dont 2 après la virgule)

## Les Types de Données Courants

Voici les types de données les plus utilisés pour débuter :

### Types Numériques

| Type | Description | Exemple |
|------|-------------|---------|
| `INT` | Nombre entier | 42, -15, 1000 |
| `DECIMAL(p, s)` | Nombre décimal précis | 19.99, 1500.50 |
| `FLOAT` | Nombre décimal approximatif | 3.14159 |

**p** = précision totale (nombre total de chiffres)
**s** = échelle (nombre de chiffres après la virgule)

### Types Textuels

| Type | Description | Exemple |
|------|-------------|---------|
| `CHAR(n)` | Texte de longueur fixe | CHAR(5) stocke toujours 5 caractères |
| `VARCHAR(n)` | Texte de longueur variable | VARCHAR(50) peut stocker jusqu'à 50 caractères |
| `NVARCHAR(n)` | Texte Unicode (multilingue) | NVARCHAR(100) pour accents, caractères spéciaux |

**Conseil** : Utilisez `VARCHAR` ou `NVARCHAR` plutôt que `CHAR` dans la plupart des cas.

### Types Date et Heure

| Type | Description | Exemple |
|------|-------------|---------|
| `DATE` | Date uniquement | 2025-01-15 |
| `TIME` | Heure uniquement | 14:30:00 |
| `DATETIME2` | Date et heure | 2025-01-15 14:30:00 |

### Autres Types Utiles

| Type | Description | Exemple |
|------|-------------|---------|
| `BIT` | Valeur booléenne (vrai/faux) | 0 ou 1 |
| `UNIQUEIDENTIFIER` | Identifiant unique (GUID) | 6F9619FF-8B86-D011-B42D-00C04FC964FF |

## Exemples Pratiques

### Exemple 1 : Table Clients

```sql
CREATE TABLE Clients
(
    IdClient INT,
    Nom VARCHAR(50),
    Prenom VARCHAR(50),
    Email VARCHAR(100),
    DateInscription DATE,
    EstActif BIT
);
```

Cette table peut stocker :
- Un identifiant numérique pour chaque client
- Le nom et prénom (texte jusqu'à 50 caractères)
- Une adresse email (texte jusqu'à 100 caractères)
- La date d'inscription
- Un indicateur actif/inactif (1 = actif, 0 = inactif)

### Exemple 2 : Table Produits

```sql
CREATE TABLE Produits
(
    CodeProduit VARCHAR(20),
    Designation NVARCHAR(200),
    PrixUnitaire DECIMAL(10, 2),
    QuantiteStock INT,
    DateAjout DATETIME2
);
```

Cette table peut stocker :
- Un code produit (texte alphanumérique)
- Une désignation avec accents et caractères spéciaux
- Un prix avec 2 décimales
- La quantité en stock (nombre entier)
- La date et l'heure d'ajout du produit

### Exemple 3 : Table Employes

```sql
CREATE TABLE Employes
(
    NumeroEmploye INT,
    NomComplet VARCHAR(100),
    Poste VARCHAR(50),
    Salaire DECIMAL(8, 2),
    DateEmbauche DATE,
    Departement VARCHAR(50)
);
```

## Vérification de la Création

Après avoir créé une table, vous pouvez vérifier qu'elle existe :

### Méthode 1 : Requête SQL

```sql
SELECT *
FROM INFORMATION_SCHEMA.TABLES
WHERE TABLE_NAME = 'Clients';
```

### Méthode 2 : Lister les colonnes

```sql
SELECT COLUMN_NAME, DATA_TYPE
FROM INFORMATION_SCHEMA.COLUMNS
WHERE TABLE_NAME = 'Clients';
```

### Méthode 3 : Dans SSMS

Dans SQL Server Management Studio, allez dans :
- Explorateur d'objets → Bases de données → Votre base → Tables
- Actualisez si nécessaire

## Conventions de Nommage

### Pour les Tables

**Bonnes pratiques :**
- Utilisez le **singulier** ou le **pluriel** de manière cohérente dans tout votre projet
  - `Client` ou `Clients` (mais pas les deux !)
  - `Produit` ou `Produits`
- Utilisez des noms **significatifs** et **descriptifs**
- Évitez les **caractères spéciaux** et les **espaces**
- Privilégiez le **PascalCase** : `ClientsEntreprise`, `CommandesFournisseurs`

**Exemples :**
```sql
-- Bon
CREATE TABLE Clients (...);
CREATE TABLE CommandesVentes (...);
CREATE TABLE ArticlesStock (...);

-- À éviter
CREATE TABLE tbl_clients (...);  -- Préfixe inutile
CREATE TABLE data (...);          -- Nom trop vague
CREATE TABLE [Mes Clients] (...); -- Espaces
```

### Pour les Colonnes

**Bonnes pratiques :**
- Utilisez des noms **clairs** et **explicites**
- Préfixez les identifiants avec `Id` ou `Numero`
- Ajoutez un préfixe `Est` ou `A` pour les colonnes booléennes
- Évitez les **abréviations obscures**

**Exemples :**
```sql
CREATE TABLE Clients
(
    -- Bon
    IdClient INT,
    NomComplet VARCHAR(100),
    EstActif BIT,
    DateInscription DATE,

    -- À éviter
    cli_id INT,           -- Abréviation peu claire
    nm VARCHAR(100),      -- Trop court
    flag BIT,             -- Nom vague
    dt DATE               -- Abréviation cryptique
);
```

## Ordre des Colonnes

L'ordre dans lequel vous définissez les colonnes a son importance pour la **lisibilité**. Une bonne pratique est de :

1. Placer les **identifiants** en premier
2. Placer les **colonnes principales** ensuite
3. Placer les **colonnes de dates** et **métadonnées** à la fin

```sql
CREATE TABLE Commandes
(
    -- 1. Identifiant
    IdCommande INT,

    -- 2. Colonnes principales
    IdClient INT,
    NumeroCommande VARCHAR(20),
    MontantTotal DECIMAL(10, 2),
    Statut VARCHAR(20),

    -- 3. Métadonnées
    DateCommande DATETIME2,
    DateLivraison DATE,
    EstLivree BIT
);
```

## Points Importants à Retenir

1. **Une table doit avoir au moins une colonne** : vous ne pouvez pas créer une table vide

2. **Choisissez le bon type de données** :
   - Texte → `VARCHAR` ou `NVARCHAR`
   - Nombre entier → `INT`
   - Nombre décimal → `DECIMAL`
   - Date → `DATE` ou `DATETIME2`
   - Vrai/Faux → `BIT`

3. **Taille des colonnes** :
   - Soyez généreux mais raisonnable
   - `VARCHAR(50)` pour un nom est généralement suffisant
   - `VARCHAR(200)` pour une description courte
   - `VARCHAR(MAX)` pour du texte long (mais utilisez avec parcimonie)

4. **NULL vs NOT NULL** : par défaut, les colonnes acceptent les valeurs `NULL` (vides). Nous verrons comment contrôler cela dans la section sur les contraintes.

## Suppression d'une Table

Si vous devez supprimer une table (attention, cela supprime aussi toutes les données !) :

```sql
DROP TABLE NomTable;
```

Exemple :
```sql
DROP TABLE Livres;
```

**⚠️ ATTENTION** : cette opération est irréversible !

## Vérifier qu'une Table Existe avant de la Créer

Pour éviter les erreurs si la table existe déjà, vous pouvez utiliser cette structure :

```sql
-- Supprimer la table si elle existe déjà
IF OBJECT_ID('Clients', 'U') IS NOT NULL
    DROP TABLE Clients;

-- Créer la table
CREATE TABLE Clients
(
    IdClient INT,
    Nom VARCHAR(50),
    Prenom VARCHAR(50)
);
```

Ou en version plus moderne (SQL Server 2016+) :

```sql
DROP TABLE IF EXISTS Clients;

CREATE TABLE Clients
(
    IdClient INT,
    Nom VARCHAR(50),
    Prenom VARCHAR(50)
);
```

## Exemple Complet

Voici un exemple complet de création d'une base de données et d'une table :

```sql
-- 1. Créer la base de données
CREATE DATABASE GestionBibliotheque;

-- 2. Sélectionner la base de données
USE GestionBibliotheque;

-- 3. Créer une table
CREATE TABLE Livres
(
    IdLivre INT,
    Titre VARCHAR(150),
    Auteur VARCHAR(100),
    ISBN VARCHAR(20),
    AnneePublication INT,
    NombrePages INT,
    PrixAchat DECIMAL(8, 2),
    DateAjout DATE,
    EstDisponible BIT
);

-- 4. Vérifier la création
SELECT COLUMN_NAME, DATA_TYPE, CHARACTER_MAXIMUM_LENGTH
FROM INFORMATION_SCHEMA.COLUMNS
WHERE TABLE_NAME = 'Livres';
```

## Résumé

- `CREATE TABLE` crée une nouvelle table dans votre base de données
- Une table est composée de **colonnes** avec des **types de données** spécifiques
- Syntaxe : `CREATE TABLE NomTable (Colonne1 Type, Colonne2 Type, ...);`
- Choisissez des noms clairs et des types appropriés pour vos colonnes
- Utilisez `DROP TABLE` pour supprimer une table (ATTENTION : irréversible)
